2　同じ目的のセッションを同時に開かない 採用（新しく立てるときに古いほうを閉じる）

決まり（利用者）：AI ツールに関係なく、同じ目的に紐づくセッションは同時に開かない。オーケストレーターはリポジトリに1つ。
キャッシュの有効時間は目的の期限ではなく、AI ツールのプロンプトキャッシュの有効時間。Claude Code では、立ち上げて Resume するセッション（会話そのもの。-p も同じ）はサブスクリプションの範囲内なら1時間、API キーや利用クレジットなら5分。サブエージェントは5分。値は AI ツールのアダプターが持つ（原典：code.claude.com/docs/en/prompt-caching.md 271行 ・ 335行、2026-10-24 取得）。Q11 #3 ・ #4 で「切れたあとの再開は全履歴を読み直すので高い。新しく立てて引き継ぐ」と決めた値

3　再開か新規かを、費用で比べる（案）

比べる式は契約（Semantic Agent Schema）が持ち、料金の倍率 ・ 有効時間 ・ 履歴の量 ・ ターン数は AI ツールのアダプターが返す。見込みのターン数は、閉じたセッションの実測の中央値。実測が無いあいだは 0（最初の1回だけで比べる）。設定ファイルで上書きできる。Claude Code の倍率は原典で照合済み、ほかのツールの値は未確認

AI ツールのアダプターが返す値（契約の形）{ "rates": { "uncached": 1, "cacheWrite": 2, "cacheRead": 0.05 },  "cacheLifetime": "PT1H",  "history": 200000, "lastUsedAt": "09:10", "turns": 34 }
再開新規＋引き継ぎ
有効時間内cacheRead × 履歴 ×（1 ＋ 見込み）cacheWrite × 引き継ぎ ＋ cacheRead × 引き継ぎ × 見込み
有効時間切れcacheWrite × 履歴 ＋ cacheRead × 履歴 × 見込み同じ
