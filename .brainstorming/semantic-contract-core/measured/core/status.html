3　再開か新規かを、AI ツールに依らない契約で決める（案）

Q11 #3 はいま「有効時間内なら再開、切れたら新規」。履歴が大きく、そのあと何ターンも続けるなら、有効時間内でも新規のほうが安いことがある（例：履歴20万 ・ 引き継ぎ1万 ・ 20ターン、Opus 5.5 ・ 1時間で、再開 21万に対し新規 3万）。比べ方を契約に置き、値をアダプターが返す

契約（Semantic Agent Schema が持つ）アダプター（AI ツールごとに差し替える）
セッションID は {ツールの種類, 文字列}。同じ目的は同時に開かない。オーケストレーターはリポジトリに1つID を発行する。再開できるかを答える
再開か新規かの決め方再開の費用と、新規＋引き継ぎの費用を比べ、安いほうを選ぶ。比べる式は契約が持つ次の値を返す：いまの履歴の量 ・ 最後に使った時刻 ・ キャッシュの有効時間 ・ 料金の倍率（書く ・ 読む）
引き継ぎの量確定した変更の記録から引き継ぎのプロンプトを作り、その量を数える（Q11 #6）量の数え方（トークン）
Claude Code の値（原典で照合済み）—会話そのもの：サブスクリプション内は1時間、API キーなどは5分。サブエージェント：5分。書く 1.25倍（5分）・ 2倍（1時間）、読む 0.1倍（Opus 5.5 ・ Sonnet 5.5 は 0.05倍）
Codex などの値—未確認。アダプターを書くときに原典で照合する
