決めたことの全体

アーキテクチャ ・ ドメインサービス ・ Semantic 系 ・ セッションの話で決めたことを1枚にまとめた。詳しい中身は各頁にある。まだ正本（ボード ・ model.json ・ Abstract のファイル）には適用していない。承認されたら、この頁を変更前と変更後として ACDR にまとめて適用する

ドメインサービスは4つ、domain の crate は8つ。基盤のコマンドは「手順を返すセマンティック系」と「処理する機械的な系」に分かれる。子のセッションは「単発か継続か」×「親の文脈を引き継ぐか」で4つの型になり、4つの AI ツールすべてで引き継げる。Abstract のファイルは11個になり、DB の表はセッションに1列足す
