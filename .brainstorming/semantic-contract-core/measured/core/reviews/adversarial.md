## 4. 全体の所見

1. **9件の多くが、A2（変更の項目を外す）を前提にしている。** A2 を採ると、A1（1単位＝1意図）・ A8（まとめられたとき）・ A3 の操作 (3) が要る。A2 を採らなければ、どれも要らない。利用者に聞くべき根幹の判断は、この1つである：「変更の項目を記録に残す」か「未確定の変更に入る意図を1つまでにし、意図ごとの欄は前後と I33 から導く」か。
2. **実際に必要な制約は、確定の単位ではなく未確定の単位にある。** I33 の判定は未確定の変更の前後で行うので、意図ごとの前後が要るのはこのときだけである。確定したあとは I33 の判定した値で意図ごとに分けられる（A8 の方法）。そのため、A1 の「1単位＝1意図」は「未確定の変更に入る意図は1つまで（破れたら例外）」に置き換えられる。これなら squash にも PR にも依存しない。ただし、AI の validator が無い文脈の U13 は残る問題である。
3. **前提（前後だけを受け取る）に反するのは A3 の操作 (3) と、A1 の「単位の並び」である。** 操作 (2) 出した者と (4) 消した ID の履歴は v2 のポートにすでにあり、新しく増えた依存ではない。
4. **A1 の「人が承認した」は v2 の決定に反する。** これは文を外せば済む。
5. 9件どうしの食い違いは、A1 と A3（単位の並びを返す操作が無い）、A1 と I32（差し戻した記録が確定しない）、A8 と I16（まとめたあとに I33 が効かないと出る）の3つ。
6. A5 ・ A6 ・ A9 は、直せば残る。壊れる場面のうち、答えの方向を変えるものは見つからなかった。
