3　この数ターンの取り違え

この数ターンで間違えたこと正しい形
acdr-inspect基盤と重なるとして外した戻した。ACDR は基盤の差分を見やすくする拡張
advisorACDR の x-delegates に足す案を出した取り下げ。親のセッションが呼ぶもので、スキーマに書かない
x-viewACDR の x-extensions に足す例として出した取り下げ。見せ方はビューが持ち、Concrete は持たない
view ・ catalog ・ design-tokens ・ glossary描画は範囲外として、形も書かなかったAbstract の一員として形を書く（描画の参照の実装はまだ作らない）
