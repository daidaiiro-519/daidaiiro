記事を書く Skill を例に、AI が書いたり直したりするたびに、人に何が届くかを、前の作りと新しい作りで並べて見る。「次へ」を押すだけで進む。人は届いたものに毎回すべて答えたとして、かかった操作の回数を数える。

前の作り（第59回）

人が記事を1件ずつ承認する
人の操作 0 回

新しい作り（いまの案）

人が見るのは、変更の差分と理由と、AI が判定できなかったものだけ
人の操作 0 回
新しい作りの中で、何をどう記録したか（開く）
記事の状態は保存しない。残すのは「契約」「記事」「判定の記録（AI と人の判定。判定したときに読んだ値を残す）」だけで、機械の rule は記録せず毎回計算し直す。記事を押すと計算の中身が出る。
