# 抽象と具体の教材 ── 台本と例

動画6本ぶんの台本と、本編で使用する例の実物を保管する。
決定と根拠は `.brainstorming-board/material-abstraction/` が保持する。

## 構成

| 本 | 題 | 枚数 | 扱う判断 |
|---|---|---|---|
| 1 | イントロ | 6 | 高さという見方と、3つの決めること |
| 2 | 言葉 | 5 | 1つの語に複数の意味が入る状態を解消する |
| 3 | 範囲 | 5 | 材料のどこから採取するかを確定する |
| 4 | 条件 | 5 | どの項目にも必ず在るものを確定する |
| 5 | 抽象と具体 | 5 | 3つを足す作業が高さの調整であることを示す |
| 6 | 直し方 | 5 | 症状から見る場所を決定する |

1本の型は、見せる → 絞る → 原因 → 足す → もう一度 である。終わりに、受講者が実施する1手を置く。

## 走る例

「課題を整理して」という1つの依頼が、6本の全体で成長する。
足す文は3つだけで、意味・範囲・条件が1本ずつ対応する。

## 置いてあるもの

| 場所 | 中身 |
|---|---|
| `lesson-0N-*.json` | 台本。枚ごとに、見出し・スライドの文面・読み上げの文を保持する |
| `examples/teirei-05.md` | 2本目で渡す議事録1本 |
| `examples/minutes-folder/` | 3本目で渡す議事録のフォルダ（定例2本・合同会議1本・前の案件1本） |
| `examples/returns/` | 各本の、直す前と直したあとの返り |
| `promotion-table.md` | 昇格表。この教材の言い方と、DDD編で与える名前の対応 |

## 文体の決まり

台本の読み上げは敬体の話し言葉とする。この決まりはブレストボードが保持する決定であり、
文書の規約（漢語の述部）を台本へ適用しない。
台本以外の文書（この `README.md` と `promotion-table.md`）は規約に従う。
