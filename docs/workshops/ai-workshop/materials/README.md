# 抽象と具体の教材 ── 台本・図・スライド

動画6本ぶんの中身を保管する。決定と根拠は `.brainstorming-board/material-abstraction/` が保持する。

## 構成

| 本 | 題 | 枚数 | 扱う判断 |
|---|---|---|---|
| 1 | `抽象の高さを知る ── 思ったとおりに返ってこない原因` | 6 | 抽象と具体の軸、抽象の高さの定義、決める3つの提示 |
| 2 | `意味を決める ── 同じ語が、同じものを指すようにする` | 5 | 1つの語に複数の意味が入る状態の解消 |
| 3 | `範囲を決める ── どこまでを対象にするか` | 5 | どこから採取するかの確定 |
| 4 | `条件を決める ── どの項目にも必ず入れるもの` | 5 | どの項目にも必ず在るものの確定 |
| 5 | `抽象の高さを合わせる ── 3つを決めることの意味` | 5 | 3つを足す作業が高さの調整であることの提示 |
| 6 | `揺らぎを直す ── 高さを見極めると、再現性が出る` | 6 | 症状からの見る場所の決定と、再現性の提示 |

1本の型は、見せる → 絞る → 原因 → 足す → もう一度 である。
**受講者への課題を置かない** ── 視聴だけで完結させる。

決める3つの呼び名は、意味 ・ 範囲 ・ 条件で固定する。「言葉」と混在させない。

## 走る例

「課題を整理して」という1つの依頼が、6本の全体で成長する。
足す文は3つだけで、意味・範囲・条件が1本ずつ対応する。

## 置いてあるもの

| 場所 | 中身 |
|---|---|
| `lesson-0N-*.json` | 台本の正本。枚ごとに、見出し・スライドの文面・読み上げの文を保持する |
| `ledes.json` | 枚の頭に置く1文 |
| `lesson_visuals.py` | 図。企画デッキの `visuals.py` の部品と配色を使用する |
| `build_lessons.py` | スライドを組む。企画デッキと同じ型（`deck-template.html`）を使用する |
| `check_figures.py` | 図の検査。画布の外・文字の重なり・箱からのはみ出し・円の縁への接触・同じ段の箱の揃いを検出する |
| `decks/lesson-0N-*.html` | 組み上がったスライド |
| `decks/lesson-0N-*-script.md` | 読み上げ原稿。音声のSkillへ渡す入力のもと |
| `previews/` | 全枚の描画結果 |
| `examples/` | 本編で使用する議事録と、直す前・直したあとの返り |
| `promotion-table.md` | 昇格表。この教材の言い方と、DDD編で与える名前の対応 |

## 組み直す

```
python3 check_figures.py      # 図の検査。1件でも出れば直してから組む
python3 build_lessons.py      # 6本ぶんのスライドと読み上げ原稿を出す
```

## 文体の決まり

読み上げは敬体の話し言葉とする。ブレストボードが保持する決定であり、
文書の規約（漢語の述部）を読み上げ原稿へ適用しない。
この `README.md` と `promotion-table.md` は規約に従う。
