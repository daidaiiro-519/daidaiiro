# 終わりに　この6本のまとめ ── 次の教材へ

枚数 3（表紙1・本編2）　読み上げ 1281字

## 01　もとの依頼に、3つを書き足しただけです

この6本でやったことを、1枚にまとめます。もとの依頼は、課題を整理して、だけでした。そこに、意味と範囲と条件の3つを書き足しました。完成した依頼を、3つのまとまりに分けて読み上げます。まず、もとの依頼です。課題を整理してください。ここから意味です。課題とは、次の打ち合わせで決定しないと、案件の進行が止まるものです。経費の精算業務の中で解決できるものと、システムの開発の中で解決できるものは含めません。ここから範囲です。見るのは、今回の案件で、本番の切り替えまでに決めるものです。次のフェーズの話と、定例で出た別案件の話、全社の連絡事項は含めません。ここから条件です。どの項目にも、誰が決めるかと、いつまでかを必ず入れてください。すでに決まったものは含めないでください。決定の期限の早い順に並べてください。以上です。もとの依頼に、この3つを足しただけです。見出しの言い回しを指定したり、返ってくる形を細かく決めたりはしていません。表にしてください、とも書いていません。細かく書いたのではなく、3つを決めただけです。ここが、この6本の結論です。これが、抽象と具体という見方の中身でした。

## 02　同じ「課題」という語が、業務ごとに別のものを指します

この6本の話は、1つの業務の中だけで進めてきました。案件の進行管理という業務の中の、課題を整理する、という作業です。その中では、課題という語の意味を、こちらで決めることができました。決定しないと進行が止まるもの、という意味です。ここで、この動画を止めて、やっていただきたいことがあります。今週の自分の議事録を1本開いてください。そこに、課題を整理して、と頼んで、返ってきたものを見ます。自分が手で直したところを3つ書き出してください。それが、あなたの条件です。意味は、こう書いてください。自分の業務の目的を1文にして、その目的に要るものだけを、なになにとは、の形で書きます。範囲は、いま渡している資料の中から、目的の外に在る話を3つ挙げます。それは含めません、と書きます。次に会うまでに、3つを書いて3回試してきてください。では、次の教材の話をします。同じ案件には、3つの業務が関わっていました。経費の精算業務、案件の進行管理、システムの開発です。この3つの業務とも、課題という同じ語を使っています。ただ、指しているものが違います。経費の精算業務で課題といえば、日々の精算が止まる要因です。案件の進行管理なら、決定しないと進行が止まるもの。システムの開発なら、実装が進まない要因を指します。どれも間違っていません。その業務の中では正しい意味です。ここで困ることが起きます。業務をまたいで話すとき、同じ語を使っているのに、指しているものが違う。そのまま話を進めると、合意したつもりで別のことを決めています。次の教材では、そこを扱います。次の教材で扱うのは3つです。業務の切れ目をどこに引くのか。その内側で言葉をどう揃えるのか。そして、境目をまたいで話すときに同じ語をどう扱うのか。この3つを順に見ていきます。そして、この考え方には名前があります。次の教材で、その名前を紹介します。
