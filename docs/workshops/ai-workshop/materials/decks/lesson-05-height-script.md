# 5本目　抽象の高さを合わせる ── 3つを決めることの意味

枚数 6（表紙1・本編5）　読み上げ 1347字

## 01　もとの一言に、3文を足しました

ここまでで、依頼はこうなりました。もとは「課題を整理して」の一言でした。そこに、意味を1文。まだ決まっていないことで、決定済みのものと、起きるかどうか分からないものは含めない。範囲を1文。今回の案件の定例、直近5回だけを見る。条件を1文。どの項目にも、誰が決めるかと、いつまでかを必ず入れる。足したのは3文だけです。見出しを指定したり、出力の形式を細かく決めたりはしていません。表にしてください、とも書いていません。ここを確認しておいてください。細かくしたのではなく、3つを決めただけです。

## 02　依頼はそのままで、材料のほうを替えてみます

依頼はそのままで、材料のほうを替えてみます。今週の定例を渡すと、6件返ってきます。来週の定例を渡すと、4件。担当している案件が違う人の、別の案件の定例を渡すと、9件。中身はまったく違います。通知の方式の話も出てきませんし、締めの日の話も出てきません。件数も違います。それでも、返ってきたものは、どれも、誰が決めるかと、いつまでかが付いた、まだ決まっていないことの一覧です。自分の担当ではない案件に対しても、同じ依頼がそのまま使えています。1本目で、毎回おなじ文章が返ってくるという意味ではない、と言いました。いま起きているのは、そういうことです。中身は変わり、形は変わりません。

## 03　いまの依頼は、高すぎる側と低すぎる側の間にあります

ここで、1本目の話に戻ります。高さとは、その依頼が当てはまる場面の広さのことでした。いちばん高いのは、もとの「課題を整理して」です。どんな一覧でも当てはまります。そのかわり、何が返ってくるかは決まりません。いちばん低いのは、1行目に通知の方式、2行目に締めの日、と中身まで指定する書き方です。そのとおりのものが返ってきますが、来週の議事録にはもう使えません。いまの依頼は、その間にあります。中身は指定していません。形だけを指定しています。この高さだと、材料が替わっても目的の中に収まり、しかも同じ依頼を使い回せます。高すぎる側にも、低すぎる側にも寄っていません。

## 04　意味・範囲・条件を決めることが、高さを合わせることでした

2本目から4本目まで、抽象とか具体とかいう語は、ほとんど使いませんでした。やったのは、意味を決めて、範囲を決めて、条件を決める、という3つだけです。この3つが、実は高さを合わせる作業でした。意味は、並べるものの種類を決めることで、広さの上限を決めます。範囲は、どこから拾うかを決めることで、材料の側を決めます。条件は、1件ずつの中身を決めます。3つとも、書かなければAIが決めるところです。AIの決め方は毎回違うので、返ってくるものが揺らぎます。抽象度を上げる、下げる、という言い方では、何をすればよいか決まりませんが、この3つなら書けます。高さを合わせる、というのは、この3つを書くことです。

## 05　だから、材料が替わっても目的から外れません

まとめます。3つを決めると、材料が替わっても、返ってくるものが目的から外れなくなります。毎回おなじ文章が返ってくるわけではありません。それは目指していません。返ってくる場所が、目的の中に収まる。これが目指すところです。そして、その結果として、同じ依頼を次の週も、別の案件でも使えます。1回ごとに書き直さなくてよくなる、というのが、ここまでの成果です。返ってくる形が崩れるときは、意味・範囲・条件のどれかが決まっていません。次の6本目では、そこをどう見つけるかを扱います。
