# 昇格表 ── 教材の言い方と、後続のDDD編で与える名前

この教材は、ドメイン駆動設計の用語を使用しない。扱う概念は同一で、呼び方だけが異なる。
後続のDDD編は、**新しい概念を追加せず、ここで対象とした判断に名前を与える**ところから開始する。

| この教材の言い方 | 何を指すか | DDD編で与える名前 |
|---|---|---|
| 同じ言葉が、同じものを指す | 1つの語が複数の意味を保持する状態を解消し、1つの意味へ固定する | 同じ言葉（ユビキタス言語） |
| 「どこまでを扱うか」 | その語の意味が成立する材料の範囲を確定する。範囲の外では同じ語が別の意味を保持する | 区切られた文脈（境界づけられたコンテキスト） |
| 外せないこと | その範囲の中で、常に成立する約束 | 不変条件と、それを保持する単位（集約） |
| 当てはまる場面の広さ（抽象と具体） | 目的に対する表現の高さ。高さが具体の表現の幅を決定する | 目的のための模型（モデル） |
| 収まらないときの直し方 | 症状から見る場所を決定し、1つずつ直す | 設計の精査（リファクタリング） |

## この表の使用方法

| 場面 | 適用 |
|---|---|
| この教材（6本） | 左の列だけを使用する。右の列を提示しない |
| DDD編 | 左の列を先に提示し、右の列を与える。定義を再度説明しない |

## 出典の扱い

右の列の名前は、DDD編の作成時に原典との照合を実施してから確定する。
現時点の記載は対応の予定であり、原典の記述として提示しない。
