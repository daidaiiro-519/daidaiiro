# 昇格表 ── 教材の言い方と、後続のドメイン駆動設計編で与える名前

この教材は、ドメイン駆動設計の用語を使用しない。扱う概念は同一で、呼び方だけが異なる。
後続のドメイン駆動設計編は、**新しい概念を追加せず、ここで対象とした判断に名前を与える**ところから開始する。

## はじめに（3つの教材にまたがる前置き）で使用した言い方

前置きは、教材2で与える名前を1つも提示しない。**指すものを先に見せ、名前は教材2が与える。**

| はじめにの言い方 | 何を指すか | ドメイン駆動設計編で与える名前 |
|---|---|---|
| 「業務」　1つの案件に、3つの業務が関わる | 目的が1つに定まる仕事の単位。案件はこれの組み合わせで進行する | 業務領域（サブドメイン） |
| 「作業」　業務は、いくつもの作業でできている | 誰が・何のために・何を受け取り・何を返すかの4つが1つに定まる単位 | ユースケース |
| 「区切り」　言葉が通じる区切り | 同じ語が同じものを指す範囲。区切りの外では、同じ語が別のものを指す | 境界づけられたコンテキスト |
| 「業務の言葉を揃える」 | 業務で使用する語を、その語が通じる区切りの中で1つの意味へ固定する | 同じ言葉（ユビキタス言語） |
| 「そのまま、作るものの形にする」 | 統一した語を、会話の中だけで保持せず、作るものの中へそのまま出す | 目的のための模型（モデル） |

## 教材1の本編（6本）で使用した言い方

| この教材の言い方 | 何を指すか | ドメイン駆動設計編で与える名前 |
|---|---|---|
| 「意味」　意味を決める | 1つの語が複数の意味を保持する状態を解消し、1つの意味へ固定する | 同じ言葉（ユビキタス言語） |
| 「範囲」　範囲を決める | その語の意味が成立する材料の範囲を確定する。範囲の外では同じ語が別の意味を保持する | 区切られた文脈（境界づけられたコンテキスト） |
| 「条件」　条件を決める | その範囲の中で、常に成立する約束 | 不変条件と、それを保持する単位（集約） |
| 「抽象の高さ」　高さを合わせる | 目的に対する表現の高さ。高さが具体の表現の幅を決定する | 目的のための模型（モデル） |
| 「直し方」　揺らぎを直す | 意味・範囲・条件の順に上から見て、1つずつ直す。症状は、どこを疑うかの手がかりに留まる | 設計の精査（リファクタリング） |

**「直し方」の順序は、教材2の依存の順と一致させてある。**
上が決定していなければ下は決定できないので、症状から直す場所を決定する形にしない。

## この表の使用方法

| 場面 | 適用 |
|---|---|
| はじめに・終わりに | 左の列だけを使用する。右の列の名前を1つも提示しない |
| 教材1の本編（6本） | 左の列だけを使用する。右の列を提示しない |
| ドメイン駆動設計編 | 左の列を先に提示し、右の列を与える。定義を再度説明しない |

## 出典の扱い

右の列の名前は、ドメイン駆動設計編の作成時に原典との照合を実施してから確定する。
現時点の記載は対応の予定であり、原典の記述として提示しない。
