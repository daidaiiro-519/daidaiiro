# 現在のスライドのデザイントークン

出所: 同梱 `build_deck.py` の `CSS` と図解、`visuals.py` の色定数。
`director-deck.html` の先頭には土台の暗色テーマが残るが、後続CSSの以下の色が優先される。
機械的に再利用する場合は `../assets/design-tokens.css` を使う。

| トークン | 値 | 用途 |
|---|---|---|
| `--ground` | `#f4f1e8` | スライドの生成り背景 |
| `--surface` | `#e9e5da` | 図解・カードの面 |
| `--surface-2` | `#e1dfd3` | 二段目の面 |
| `--paper` | `#fffaf2` | 明るい面 |
| `--ink` | `#252b29` | 見出し・本文 |
| `--dim` | `#59605a` | 導入・説明 |
| `--faint` | `#686f65` | 補助テキスト |
| `--line` | `#d5d6c9` | 表などの区切り線 |
| `--accent` | `#b64326` | 赤茶の強調 |
| `--accent-dim` | `#873f2b` | 濃い強調色 |
| `--canvas` | `#deded3` | ステージ外側の背景 |
| `--diagram-line` | `#a8b09f` | `visuals.py` の図解の線 |
| `--on-accent` | `#fffaf2` | 強調面上の本文 |
| `--on-accent-dim` | `#fff1e9` | 強調面上の補足 |

末尾4トークンは既存の固定色に再利用用の名前を付けたもの。
既存ビルダーはそれらを自動で読み込まない。色の正本は生成元にあり、変更時は
この表とCSS資産も同期する。既存SVGには矢印などの補助色もあるため、
配色変更では上記の定数だけでなく対象SVGの `fill` / `stroke` も確認する。

## 書体・寸法

| 項目 | 現行値 |
|---|---|
| ステージ | 1280×720、16:9 |
| スライド余白 | 上84px・左右84px・下78px |
| 本文領域の幅 | 1112px |
| 基本文字 | Noto Sans JP → Hiragino Sans → Yu Gothic → sans-serif |
| 見出し | サンセリフ、700、字間 −0.03em |
| 表紙タイトル | 61px、行高1.4 |
| 本編見出し | 36px、行高1.46 |
| 冒頭の目的スライド見出し | 47px、行高1.43 |
| 導入 | 20px、行高1.7 |
| 表の本文 | 基本19px、行高1.65（密度に応じた既存の個別指定あり） |
| 注記 | 基本16px、行高1.8 |
| 図の角丸 | 8〜12px |

生成りを広く取り、濃いグレーの文字と赤茶の強調で主従を作る。
新しい虹色の分類色を足す前に、位置・ラベル・線の違いで区別できるか考える。
対比は形と情報の粒度を揃える。見出し下の飾り線は現行CSSで非表示にしている。
