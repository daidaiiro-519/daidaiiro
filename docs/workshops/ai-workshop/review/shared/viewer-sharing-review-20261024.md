# 画面構成の共同制作への共有確認

対象は画面の案内、共同作業の入口、別セッションの開始用プロンプト、共通制作ガイド、担当情報、共有メモリ、変更記録である。生成した制作情報の画面にも案内を追加した。

## 文書の10判定

1. 対象：画面構成の確認と、教材の内容の承認を区別した。
2. 型：画面とURL、入力と生成先を表で対応させた。
3. 数：メイン、比較、閲覧、制作情報、遷移図の五つを列挙した。
4. 見出し：入口、往復、生成元、別担当の追加、版と確認、検査へ分けた。
5. 結論：利用者が画面構成を確認して共同制作への共有を依頼したことを最初に記載した。
6. 対応：画面の名前とリンク先を対応させた。
7. 用語：公開HTML、編集する入力、生成処理、担当情報を区別した。
8. 読み手：別セッションの担当が、会話を知らなくても公開先へ修正を追加する方法を参照できる。
9. 量：メモリには現在地と参照先だけを追加し、生成方法の詳細は画面の案内に置いた。
10. 比喩：新しい比喩や造語は使用していない。
