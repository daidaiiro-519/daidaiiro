# オリエンテーション全14枚の通し読み

利用者の指示で、全14枚を通して読んで理解できるかを、新しい文脈のHaiku 5.5の1体に確認させた。受講者は、ワークショップの目的、学び方、受講後の目標、次にすることを正しく読み取った。

通しで読んだことで、教材カードの見出しが1・8・14枚目で違うこと、判断用の資料の欄名が6・9枚目で違うこと、11枚目の「成果物」の意味が5〜7枚目と違って見えることが分かった。これらと、7枚目の成果物が例であること、三教材の名前の繰り返し、「目的レベル」の言い添え、耳で追いにくい文を修正した。採否の一覧は[レビューの記録](../../proposal-orientation-20261024/orientation-20261025/review/haiku-review-20261026-whole/README.md)にある。

図を変えたのは1・7・9・11・14枚目で、ほかは原稿だけを修正した。14枚目は見出しが長くなって矢印にかかったため、3枚の見出しの文字を一段小さくして再描画した。直前版はiterations/20261026-whole-review-before/。比較は http://127.0.0.1:8772/design-review.html?deck=orientation&slide=1#slide-comparison 。正本と音声動画は変更していない。

受講者が知りたいこととして、社内の業務データや機密情報をAIに渡してよい範囲が挙がった。利用者が「これは今回のテーマではない」と判断したため、オリエンテーションでは扱わない。修正は利用者確認待ちである。
