# オリエンテーション5枚目：確認と修正、照合する対象

利用者の指示で5枚目を見直した。2〜4枚目は次の枚への指示を受けて確認済みとした。5枚目は利用者確認待ち。観点は担当情報のreview_criteriaの10項目である。

## 見つけた点と変更

| 観点 | 変更前 | 変更後 |
|---|---|---|
| 前後の重なり | 見出し「作成は速くなった。確認や修正まで含めると、どうでしょうか？」と帯が3枚目の問いと同じ | 見出しは4枚目の問いを受ける「作れる成果物が増えたとき、確認と修正はどうなりますか？」、帯はこの枚の結論「作成の時間が短くなっても、確認と修正の時間が同じように減るとは限らない」 |
| 前後の重なり・過去のレビュー | 左側のPM・PLと開発者の発言が4枚目の繰り返しで、職種の固定分担にも見える | 「AIで作った成果物」の箱に、成果物が増えると照合する対象も増えることがあると示した |
| 枚の中の重なり | 導入文「人が内容を確かめ、必要なら修正・再確認」が図の下段と同じ | 「AIが作った成果物も、人が元の情報や要件と照合してから、仕事で使います。」 |
| 図と原稿の一致 | 原稿の「成果物どうしの食い違い」が図にない | 右の見出しを「元の情報や仕様、成果物どうしを照合する」にした |
| 語の言い換え | 原稿「照らし合わせたり」、対象が分からない「記録」 | 図と同じ「照合」、「元の情報や要件」 |
| 原稿 | 「図の下の矢印は、この流れを示しています」、「確認が必要ですね」 | 図の見方の説明と「ね」を外した。確認する点を並べてから「こうした点を確認します」とまとめた |
| 次の枚との重なり | 結びの「確認したい内容を探すだけで時間がかかったり」が6枚目の冒頭と同じ | 「成果物の量だけでなく、その内容と示し方にも目を向ける必要があります」で6枚目へつなぐ |

右側の照合の図、元の情報・要件仕様と重ねた成果物、修正と再確認の戻りの表現は残した。資料と開発の区別は右側の2行で示す。共通の「はじめに」は案件の具体で確認範囲の広がりを扱う。5枚目は一般的な確認の流れにとどめ、食い違いはない。

## 文章の10判定

1. 読み手：部内の受講者が、AIで作った成果物を確認する場面を想像できる。
2. 主張：作成が速くなっても、確認と修正の時間は同じように減るとは限らない。
3. 論：確認する点、修正と再確認、照合対象の増加、6枚目への接続の順に進む。
4. 構造：作った成果物から確認へ矢印でつなぎ、修正と再確認を戻りで示した。
5. 文：確認する点を並べ、一つの動詞でまとめた。
6. 文体：原稿は敬体を維持した。
7. 語彙：照合、確認、修正を図と原稿でそろえた。
8. 重複：3・4・6枚目と、導入文と図の下段の重なりを外した。
9. 表記：疑問の見出しに疑問符を付けた。
10. 根拠：照合対象の増加は「ことがある」とし、断定していない。
