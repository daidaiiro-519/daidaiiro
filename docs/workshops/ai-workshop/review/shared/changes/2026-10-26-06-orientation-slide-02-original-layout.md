# オリエンテーション2枚目：見直し開始時の図の構成へ戻す

利用者が見直し開始時の2枚目の画像を示し、「背景も分かっていいデザイン」と指摘した。変更記録05の「3つの流れ」の図をやめ、開催の背景→ワークショップの位置づけ→目指す姿の帯という元の構成へ戻した。2・3枚目は利用者確認待ち。

## 変更

構成とアイコンは見直し開始時の版のまま、文言を最新の方針に合わせた。

| 要素 | 見直し開始時 | 今回 |
|---|---|---|
| 開催の背景 | この力を、仕事で実現したいことに合わせて使いたい | この力を、自分の仕事の改善に活かしたい |
| 考え方を学ぶ | 何を実現したいか／そのために何が必要か | 目的と要件の明確化／業務のモデル化と設計 |
| AIで実践する | Agents・Skillsで実行し／結果を確かめる | 観点と手順をSkillsにまとめ／Agentsで実行し、結果を確かめる |
| 位置づけの補足 | 部内のAI活用を進めるための、学習と実践の場 | 結果から、Skillsと進め方を改善する |
| 目指す姿 | 自分の仕事の目的を、AIで達成できる | 自分の仕事に合ったSkillsを作り、Agentsで仕事を進められる |
| 導入文 | 目的と必要な条件を考え、Agents・Skillsで実践し、仕事の目的をAIで達成する力を身につけます。 | AIで実現できることが広がった今、その力を自分の業務で活かす考え方を学び、AIで実践します。 |

背景は「これまで難しかったことも実現できる」のままとし、3枚目の「作りやすく、速く」とは分けた。確認・修正と品質の話は3枚目に任せる。目指す姿は、変更記録04で利用者が求めた「ワークショップでできるようになること」を帯で示す。導入文は帯と同じ文にならないよう、背景と位置づけを述べる文にした。見出しは了承済みのまま変えていない。見出しが2行になったため、図の縦幅を418から350へ詰めた。

原稿は、背景、位置づけ（学ぶ内容、Skillsにまとめ、エージェントで実行し、結果から改善する）、目指す姿、3枚目の問いへの接続の順にした。構成案story-plan.mdと.jsonの2枚目の行も同じ内容へ更新した。

その後、利用者から原稿が伝わりにくいと指摘を受けた。長い1文に判断の観点と手順・スキル・エージェントを詰めていた箇所と、二つの考え方を1文に並べていた箇所を、1文に一つのことを述べる形に分けた。帯の「Skillsを整え」も、何をするかが分かる「Skillsを作り」に変えた。

## 文章の10判定

1. 読み手：部内の受講者が、開催の背景と受講後の姿を読み取れる。
2. 主張：背景から位置づけ、目指す姿へ進む。
3. 論：図と原稿を同じ順序にした。
4. 構造：背景と位置づけは矢印、目指す姿は下の帯で示した。
5. 文：何を学び、何にまとめ、何で実行するかを書いた。
6. 文体：原稿は敬体を維持した。
7. 語彙：教材の紹介名、判断の観点と手順を共通方針の語で書いた。
8. 重複：3枚目と重なる作りやすさと確認・修正の話を外した。
9. 表記：原稿ではエージェントとスキルを読み方で書いた。
10. 根拠：目指す姿として述べ、できることを保証していない。
