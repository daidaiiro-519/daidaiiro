# 企画書の正式反映

利用者が2026年10月26日から28日にかけて、企画書の詳細版の全38枚を1枚ずつ確認した。アンケートの設計書2本も確認した。ACDR 0209の承認を受け、確認済みの版を正本へ反映した。

## 反映したもの

| 対象 | 内容 |
|---|---|
| `proposal/src/` | build_deck.py、visuals.py、survey.json、build_survey_docs.py |
| `proposal/out/` | 詳細版と要点版のスライド・1ページ版・発表原稿・PDF、一覧画像、アンケート・効果測定案、Formsの作成用プロンプト |
| `proposal/out/versions/v3/` | 反映前の版。README の版の表に v4 を加えた |
| `README.md` | 枚数、運営案の状態、設計書の説明、版の表 |

パスは docs/workshops/ai-workshop/ からの相対パス。

## 主な変更

企画の目的を、旧い到達像の「目的を言葉にしてAIに伝え、達成する」から「AIの活用を、仕事全体の生産性と品質の改善につなげる」に改めた。正式版のオリエンテーションと同じ到達点である。「この企画の本質」の枚を外し、目的の枚を背景の次へ移した。例は「はじめに」の経費精算システム刷新の事例にした。主KPIは、目的と要件の明確化率と、改善の達成率である。アンケートは、事前7問、参加時は改善1件で8問に絞った。回答フォームは、ワイヤーフレームで示した。定員は15〜20名、Kiroの費用は月 $300〜$400 である。

## 確認

作業コピーで正本と同じ名前に生成した成果物は、正本で生成し直した成果物と一致した。企画書の部品を読み込む教材の14本も確認した。オリエンテーション、「はじめに」、教材1、教材2で、出力は1バイトも変わらない。

## 残っていること

運営設計案（proposal/out/workshop-plan.md）は手で書いた文書である。旧教材名と旧い到達像が残っており、別に見直す。
