# 構成案の文書確認

対象：assessment.md。2026年10月24日。doc-writing-skillsのcheckは指摘0件で通過した。

1. 指し先：資料名、枚番号、版、生成元を明記した。
2. 情報の型：現状と提案、図の役割、構成を表で分けた。
3. 数：要点版・詳細版44枚と、オリエンテーション14枚の内訳を明記した。
4. 見出し：確認した版、差分、図の役割、資料別の構成、根拠、次の作業を対応させた。
5. 結論：部長の判断と部内メンバーの学びに合わせて直す方針を先頭に示した。
6. 対応：現行の説明と修正案、各図の関係と残す役割を同じ行に置いた。
7. 用語：文脈の境界と集約の境界、期待する効果と確認結果を区別した。
8. 読み手：現行の表現を具体的に挙げ、必要な専門語に説明を添えた。
9. 量：一枚ずつ修正する前の構成確認に必要な範囲で、根拠はIDと適用箇所を示した。
10. 比喩：新しい比喩や造語を使わず、人物・書類・工程・参照関係の名前で説明した。
