# その成果物は、確認・判断ができる形になっていますか？

図の左は、AIで作った成果物が多く、資料ごとに形式や詳しさも違う状態です。確認する人は、確認したい内容を探すところから始めなければなりません。形式を決めていても、情報量が多ければ、読むだけで時間がかかります。

そこで考えたいのが、その成果物を何のために使い、何を確かめたいのかです。使う目的に合わせて、含める内容、対象の範囲、必要な詳しさ、示し方を決めます。

図の右は、承認に使う資料の例です。何を決めるのか、その根拠は何か、満たす条件や未確認の点は何かが分かり、必要なら詳細も確認できます。設計書やコード、テストでも、どの要件に対応し、何を確認すればよいかが分かる形が必要です。

ただ短くしたり、すべてを同じ形式にしたりすればよいわけではありません。判断に必要な情報を残したうえで、人が確認できる内容と示し方にします。

では、何のために、何をどこまで作り、何を確かめればよいのか。皆さんは、それを自分で説明し、AIにも伝えられるでしょうか。
