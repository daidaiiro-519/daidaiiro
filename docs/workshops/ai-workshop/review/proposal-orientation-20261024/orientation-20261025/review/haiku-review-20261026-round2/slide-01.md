# 1枚目　受講者（Haiku 5.5）レビュー2回目

## 読み取れたこと
- AIを使って仕事全体の生産性と品質を高めるワークショップで、3つの教材で学ぶことが示されている。
- 3つの教材は「目的と要件の明確化」「業務のモデル化と設計」「AI活用の実践と改善」の順だと読めた。

## 図で分かりにくかったところ
- 3つのカードの下にあるテキストが小さく、教材ごとの違いが一目で分からない。
- 「教材1 何を実現し、満たすか」のように、見出しと説明が別の言葉で書かれていて、どれが要点か迷う。
- 下部の「← → でめくる」や「表紙」「1 / 14」は、動画で見せる画面では操作用の表示で、受講者には不要に見える。

## 図と原稿が合っていないところ
- 原稿は「資料やコードを速く作れることに加えて、必要な品質を満たし」と言うが、スライドには速さや品質の話は出てこない。
- 原稿は「三つの教材」と言うが、スライドには「教材1〜3」のラベルがあるだけで、どれが「それらをエージェントやスキルを使ったAIの作業で実践し」に当たるかは、3枚目のカードから推測するしかない。
- 原稿は「目的と要件を明確にする考え方」と言い、カードは「目的と要件の明確化」。ほぼ同じだが、原稿は「考え方」を強調している。

## 日本語として不自然・読みにくい表現
- 「AgentがSkillsを使って作業する」: 英語の語が混ざり、文の主語と動詞の関係も読み取りにくい。
- 「AIで、仕事全体の生産性と品質を高める」: 「仕事全体の」と「生産性と品質」が続き、何の全体かが一読では掴みにくい。
- 原稿「資料やコードを速く作れることに加えて、必要な品質を満たし、確認や修正まで含めて仕事を進めやすくすること」: 一文が長く、「満たし」「進めやすくする」の主語が途中で入れ替わって読める。

## 意味が分からない語・初めて見る語
- Agent: 初めて見る語で、スライド内に説明がない。
- Skills: 同上。「スキル」と読むのか英語のままなのかも示されていない。
- 業務のモデル化: 「モデル」が何を指すのか、業務をどう表すのかの説明がない。

## 前後の枚とのつながりで引っかかったこと
- 次の枚の見出し「AIを仕事の改善につなげる考え方を学び、実践するワークショップです」は、この枚の結びと内容が近く、この枚で話し切ったように聞こえる。
- この枚は1枚目なので前の枚は無いが、「まず、このワークショップを開く背景と、目指すことからご紹介します」という原稿の予告に対応する背景の枚がこの枚では示されず、次の枚で補われるのかが分からない。

## 自分で補った前提
- 「Agent」は、AIが目的に向けて自分で作業を進める仕組みだと推測で補った。スライドと原稿には定義がない。
- 「Skills」は、AIに手順や知識を渡す仕組みだと推測で補った。
- 「業務のモデル化」は、仕事の流れや情報を整理して図や表で表すことだと推測で補った。

## 受講者として知りたいと思ったこと
- Agent と Skills が何で、なぜこの3つの教材に出てくるのか。
- 3つの教材は、この順に学ぶと何ができるようになるのか。
- この研修の対象は、開発者とPM・PLのどちらなのか、両方なのか。
