# 14枚目　受講者（Haiku 5.5）レビュー2回目

## 読み取れたこと
- 3つの教材（目的と要件の明確化、業務のモデル化と設計、AI活用の実践と改善）を順に進めると、仕事全体の生産性と品質が上がる、という流れだと受け取りました。
- 矢印は左から右への順序を示すと推測しました。図に説明はありません。

## 図で分かりにくかったところ
- 各カードに、小見出し・大見出し・説明文・補足文の4段の文字があり、1枚に情報が多いです。読む順番が決めにくく、聞きながら追うのも大変でした。
- 補足文（「作業の目的に合わせて、満たす要件を明確にする」など）は小さく薄い灰色で、画面では読みにくいです。
- 3枚目のロボットのアイコンが、AIのAgentを指すのかは図から分かりません。
- 最後の赤い円が「仕事全体の生産性と品質を高める」の結果を指すと推測しました。矢印が円へつながっているため、そう読めました。
- 上の導入文の箱が、教材全体の前置きなのか、3枚目だけの前置きなのか分かりにくいです。

## 図と原稿が合っていないところ
- 原稿の「成果物を速く作ることに加えて、確認や修正まで含めた」は、図に出てきません。図の「確認」は3枚目の補足文にしかありません。
- 原稿の「工数や期間、品質がどう変わったか」は、図には出てきません。
- 見出しは「改善につなげましょう」ですが、赤い円は「高める」と書いてあり、言葉が揃っていません。
- 原稿の「経費精算システムの刷新案件」は、この枚にはなく、次の動画の説明として読み上げられます。図では次の動画の見出しのみです。

## 日本語として不自然・読みにくい表現
- 「対象・判断・関係と守る条件」（カード2の小見出し）は、何を守るのか、語の並びが不自然です。
- 「Skillsにまとめ、Agentで使う」は、日本語の中に英語の語が混ざり、読み上げでも区切りにくいです。
- 「Skillsと進め方を改善する」の「進め方」は、何を指すかが曖昧です。
- 「業務のルールと設計の対応を確かめる」の「対応」は、何と何の対応かが曖昧です。
- 原稿の「その考え方をスキルにまとめ、エージェントを使ったAIの作業で実践し、改善すること」は一文が長く、聞いていて主語と目的語を追いきれませんでした。

## 意味が分からない語・初めて見る語
- 「Skills」: 図にも原稿にも説明がなく、何を指すか分かりません。
- 「Agent」（「エージェント」）: 同上です。
- 「業務をモデルに表し」の「モデル」: 何の模型か分かりません。
- 「設計」（教材2）: ソフトウェアの設計か、業務の設計か、判断できません。
- 「工数」: 原稿で読み上げられますが、説明はありません。

## 前後の枚とのつながりで引っかかったこと
- 前の枚の結びは「このワークショップで目指すことを、もう一度確認しましょう」です。前の枚を見ていないので、「もう一度」が本当に前に説明されたかは確かめられませんでした。
- 次の枚（「はじめに」）への渡しは、「共通の題材と、教材1〜3の学習の流れ」で分かります。ただ、この枚では教材の中身の説明が薄いので、次の枚で初めて具体が見えると感じました。
- 原稿の導入文は、この枚の画面にも出ているので、同じ文を2回聞くことになりました。

## 自分で補った前提
- 「Agent」は、AIが仕事を自分で進める仕組みと補いました（推測）。
- 「Skills」は、AIへの作業手順をまとめたものと補いました（推測）。
- 「教材」は、この動画の後に続く別の動画だと補いました（推測）。
- 赤い円は、3つの教材の結果を指すと補いました（推測）。
- 前の枚の内容は見ていないため、「もう一度」の前提は補いようがありませんでした。

## 受講者として知りたいと思ったこと
- Skills と Agent が、普段の業務で具体的に何をするものか。
- 「生産性」「品質」「工数」を、自分の仕事のどの数字で測るのか。
- 教材1〜3はそれぞれどのくらいの長さで、どの順で見ればよいのか。
- 「自分の仕事のどこを改善したいか」は、今すぐ答えるべきか、後で考えればよいか。
