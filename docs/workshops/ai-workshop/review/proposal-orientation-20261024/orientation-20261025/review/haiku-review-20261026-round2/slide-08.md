# 8枚目　受講者（Haiku 5.5）レビュー2回目

## 読み取れたこと
- 3つの教材のうち、教材1と2で考え方を学び、教材3でその考え方をAIの作業で使う方法を学ぶ、という全体の流れ。
- 教材1・2の考え方が Skills にまとまり、Agent がそれを使って作業する、という流れに見えた（推測で補った。原稿の「エージェントが作業の中で使えるように」から判断した）。

## 図で分かりにくかったところ
- 教材3の矢印は Agent へ直接向いていて、教材3が Skills に関わるようには見えない。教材1・2だけが Skills へ入っている。
- Agent の箱だけ赤枠になっているが、赤の意味が説明されていない。
- 教材3と Agent の両方にロボットの絵が使われていて、区別がつきにくい。
- 下の赤い帯「三つの教材を、共通の題材で順に学ぶ」が、図のどの部分とつながるのか分からない。

## 図と原稿が合っていないところ
- 原稿は「教材3は…スキルにまとめ、…エージェントが作業の中で使えるようにします」と言うが、図では教材3から Skills への矢印がなく、教材3から Agent へ直接向いている。まとめる役が教材3なのか教材1・2なのかが図と原稿で食い違う。
- 原稿の「前の枚で見たように」は、この枚の図にない内容を指している（前の枚を見ていないため、確認できない）。
- 原稿の「題材は、このあとの『はじめに』で紹介します」に対応する表示が、この枚の図にない。

## 日本語として不自然・読みにくい表現
- 「目的は広くすればよいわけではありません。実現したいことに合う大きさを見極め、具体的な要件と作業に戻って考えます。」（「作業に戻って」が何に戻るのか分からない）
- 「業務の言葉の意味も、このモデルと設計を考えるために確かめます。」（「業務の言葉の意味」が具体的に何を指すか分からない）
- 「判断の観点と確認の手順にしてスキルにまとめ、前の枚で見たように、エージェントが作業の中で使えるようにします。」（「にして」「にまとめ」「ように」が続いて長い）
- 見出しの「業務の設計」と、教材2の「業務のモデル化と設計」で言葉が揃っていない。
- 図の「まとめ方は教材3で学ぶ」（「まとめ方」が何のまとめ方か分からない）

## 意味が分からない語・初めて見る語
- Agent（エージェント）：この枚では箱の名前だけで、何者か説明がない。
- Skills（スキル）：「判断の観点と確認の手順にまとめる」とあるが、実際に何のファイルや形なのかは分からない。
- 業務のモデル化：「モデル」が何を指すのか分からない。
- 守る条件：何を守るのか分からない。

## 前後の枚とのつながりで引っかかったこと
- 前の枚の結びは「こうしたAIの使い方を自分の仕事で実現するために」だが、前の枚の内容は確認できない（推測）。
- 次の枚の見出し「資料作成や開発の仕事で使えるようになる」と、原稿の「皆さんの仕事にどう活かせるか」はつながっている。しかし「はじめに」がこの間に入るのか次の枚なのかが分からない。
- Agent の説明が「前の枚で見たように」に頼っているため、前の枚を見ていない人には、Agent が初めて出てくる語になる。

## 自分で補った前提
- 教材3がSkillsを作って使う役だと補った（原稿の「スキルにまとめ」から推測。図からは読み取れない）。
- Agent は Skills を読み込んで作業する仕組みだと補った（図の「Skillsを使って作業・照合」から推測）。
- 「照合」は、作業の結果を Skills の確認の手順と合わせることだと補った（推測）。

## 受講者として知りたいと思ったこと
- Agent とは何か。Skills とどう違い、誰が何をするのか。
- 教材3は Skills を作るのか、使うのか。
- 「共通の題材」は何か。いつ紹介されるのか。
- 「照合」は何と何を合わせることか。
- 仕事での具体例（資料作成や開発で、どんな場面に使うのか）。
