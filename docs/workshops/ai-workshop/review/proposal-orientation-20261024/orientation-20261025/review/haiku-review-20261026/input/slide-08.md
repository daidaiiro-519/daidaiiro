# 8枚目／全14枚

## 見出し
三つの教材で、目的と要件、業務の設計、AIでの実践を学びます

## 導入文
教材1と2で考え方を学び、教材3でその考え方をAIの作業で使う方法を学びます。

## 原稿（ナレーション）
教材1は、目的と要件の明確化です。何のための作業で、どこまでを実現するのかを考え、満たす必要がある要件を明確にします。目的は広くすればよいわけではありません。実現したいことに合う大きさを見極め、具体的な要件と作業に戻って考えます。

教材2は、業務のモデル化と設計です。教材1で明確にした要件をもとに、業務で扱う対象や判断、その関係と守る条件をモデルに表し、設計へつなげます。業務の言葉の意味も、このモデルと設計を考えるために確かめます。

教材3は、AI活用の実践と改善です。教材1と2の考え方を、判断の観点と確認の手順にしてスキルにまとめ、前の枚で見たように、エージェントが作業の中で使えるようにします。使いながら改善する方法も扱います。

三つの教材は、共通の題材を使って順に学びます。題材は、このあとの「はじめに」で紹介します。ここでは、学んだことを皆さんの仕事にどう活かせるかを見てみましょう。

## 前の枚の原稿の結び
こうしたAIの使い方を自分の仕事で実現するために、三つの教材で順に学びます。

## 次の枚の見出し
学んだ考え方を、資料作成や開発の仕事で使えるようになる
