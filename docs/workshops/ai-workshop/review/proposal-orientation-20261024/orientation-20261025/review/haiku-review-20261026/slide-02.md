# 2枚目　受講者（Haiku 5.5）レビュー

## 読み取れたこと
- 社内のAI活用を仕事の改善に生かすため、三つの教材で考え方を学び、自分の仕事で Skills と Agent を試して改善するワークショップだと読めた。
- 「目指す姿」は、自分の仕事に合った Skills を作り、Agent で作業を進められるようになることだと読めた。

## 図で分かりにくかったところ
- 「開催の背景」の箱のアイコンは、ロボット・書類・モニターの3つで、何を表すか図の中に説明がない。推測では、AIと資料とアプリだが、この枚の原稿にはそれを示す語がない（補った推測）。
- 「ワークショップの位置づけ」は、教材で学ぶ → 自分の仕事で実践する、という流れを示しているが、「位置づけ」は全体の中のどこかを指す語に見える。中身は流れの説明なので、語と中身がずれている。
- 「教材で学ぶ」の箱に並ぶ3項目に番号も区切りもない。受講者は、3つの教材の名前なのか、順番のある手順なのか判断できない。
- 「三つの教材」「教材」は、この枚のどこにも中身の説明がなく、このあと詳しく紹介すると原稿にある。見出しだけでは何の教材か分からない。

## 図と原稿が合っていないところ
- 図の「この力を、自分の仕事の改善に活かしたい」は、受講者の願いの文である。原稿は「この力を…活かすために、このワークショップを企画しました」と、主催者の動機を述べている。主語と立場が図と原稿で違う。
- 図は「Agent」「Skills」と英語で書き、原稿は「エージェント」「スキル」と書く。同じ枚の中で語が揺れている。
- 原稿の「なぜこうした考え方が必要なのでしょうか」という問いに、この枚の図は答えていない。答えは次の枚に送られている。
- 図の「判断の観点と手順をSkillsに」は、原稿の「判断の観点と手順をスキルにまとめ」に対応するが、図には「まとめる」の動詞がない。

## 日本語として不自然・読みにくい表現
- 「AIで、これまで難しかったことも実現できるように」（図）: 「ように」で終わり、主節がない。見出しとして途切れて読める。
- 「判断の観点と手順をSkillsに」（図）: 動詞がなく、何をするのか読み取りにくい。
- 「Skillsと進め方を改善する」（図）: 「進め方」が、Skills の進め方か、ワークショップの進め方か曖昧。
- 「AIを仕事の改善につなげる考え方を学び、実践するワークショップです」（見出し）: 「考え方」が何を指すか、この枚では分からない。読み上げると長く、息が続かない。

## 意味が分からない語・初めて見る語
- Agents / Agent / エージェント: この枚では定義がない。受講者は、AIが自分で作業を進める仕組みと推測できるが、確かではない。
- Skills / スキル: 同じく定義がない。判断の観点と手順をまとめたもの、と原稿から推測するしかない。
- 判断の観点: 原稿で初めて出てくる。何の観点かが分からない。
- 目的と要件の明確化、業務のモデル化と設計: 専門語に見えるが、この枚では内容が分からない。
- 位置づけ、教材: 上に述べた。

## 前後の枚とのつながりで引っかかったこと
- 前の枚の結び「まず、このワークショップを開く背景と、目指すことからご紹介します」は、この枚の内容と合っている。
- 次の枚の見出し「AIで資料やアプリを作りやすくなりました。仕事全体の生産性と品質は、どう変わりましたか？」は、この枚の背景箱の「実現できるように」と話がつながる。ただし、この枚では資料やアプリに触れていないので、次の枚で急に話が変わるように感じる。
- 原稿の「では、なぜこうした考え方が必要なのでしょうか」は、次の枚への橋渡しだが、この枚から次の枚へ問いが残ったまま終わる。

## 自分で補った前提
- 図のアイコンは、ロボットがAI、書類が資料、モニターがアプリを表すと補った。図からは確定できない。
- 「教材」は、このあと紹介される3つの学習資料と補った。
- 「Agents」は、AIが作業を進める仕組みだと補った。定義はこの枚にない。
- 3項目は、番号がなくても左から右、上から下の順と補った。

## 受講者として知りたいと思ったこと
- Agents と Skills は何か、どう違うのか（この枚で一言の定義がほしい）。
- 三つの教材は何で、このワークショップのどこで使うのか。
- 「開催の背景」の具体（なぜ今この企画か。業務のどの困りごとに当たるか）。
- 完成したら何が手に入り、自分の仕事でどこまで試すのか（目指す姿の具体の場面）。
