# 8枚目　受講者（Haiku 5.5）レビュー

## 読み取れたこと
- 三つの教材を、目的と要件、業務のモデル化と設計、AIでの実践の順に学ぶ、という紹介。教材1・2で考え方を作り、教材3でそれをSkillsにまとめてAgentに使わせる流れと受け取った。

## 図で分かりにくかったところ
- SkillsとAgentの箱に定義がなく、「判断の観点と確認の手順」「照合」が何を指すのか分からない。
- 教材2のカードの「対象・判断・関係と守る条件」は名詞の並べ書きで、どこまでが一つの項目か判別しにくい。
- 下部の帯「三つの教材を、共通の題材で順に学ぶ」は原稿の一文の繰り返しで、図から新しい情報が得られない。

## 図と原稿が合っていないところ
- 原稿は「教材3が教材1・2の考え方をスキルにまとめる」と言うが、図は教材1・2の矢印をSkillsへ、教材3の矢印をAgentへ向けている。作る主体が図では逆に見える。
- 原稿末の「ここでは、学んだことを皆さんの仕事にどう活かせるかを見てみましょう」に対し、このスライドは学び方の説明のみで、仕事への活かし方は映っていない。
- 図は「Skills」「Agent」、原稿は「スキル」「エージェント」と表記が揺れている。

## 日本語として不自然・読みにくい表現
- 「具体的な要件と作業に戻って考えます。」（教材1）: 何に戻って何を考えるのか、目的語が読み取りにくい。
- 「教材1と2の考え方を、判断の観点と確認の手順にしてスキルにまとめ、前の枚で見たように、エージェントが作業の中で使えるようにします。」（教材3）: 一文が長く、挿入句で主節が遠い。
- 「業務の言葉の意味も、このモデルと設計を考えるために確かめます。」（教材2）: 言葉の意味を確かめるという行為の中身が不明。

## 意味が分からない語・初めて見る語
- Skills / スキル、Agent / エージェント: このスライド内に定義がない。「前の枚で見た」とあるが、その内容は見ていない。
- 判断の観点、確認の手順、照合、業務のモデル化、守る条件、題材: 初めて見る語で、説明がない。

## 前後の枚とのつながりで引っかかったこと
- 前の枚の結び「こうしたAIの使い方」は、前の枚を見ていないので指す先が分からない。
- 「題材は、このあとの『はじめに』で紹介します」とあるが、次の枚の見出しに「はじめに」は出てこず、題材がどこで出るか追えない。
- 次の枚の見出し（資料作成や開発の仕事で使えるようになる）が、本枚の末尾の仕事への適用の話と重なり、本枚で何を見せるかが二重に示されている。

## 自分で補った前提
- 補った: Skillsは「作業の判断基準と手順をまとめたもの」、Agentは「それを使って作業するAI」と解釈した（このスライドからは読めないので推測）。
- 補った: 矢印の教材3→Agentは「教材3の成果をAgentが使う」という意味と解釈した。
- 補った: 題材は業務の具体例（資料作成や開発）だと推測した。

## 受講者として知りたいと思ったこと
- SkillsとAgentの違い、そしてなぜ教材1・2の結果がSkillsへ向かうのか。
- 教材3はSkillsを作るのか、使うのか（図と原稿の食い違いの解消）。
- 「判断の観点」「確認の手順」の具体例が1つあれば、教材1・2のつながりが掴める。
