# 12枚目／全14枚

## 見出し
教材で学び、自分の仕事で試し、何が改善したかを確かめます

## 導入文
Skillsを作れたことだけでなく、仕事の何が変わったかを、確認や修正の内容も含めて振り返ります。

## 原稿（ナレーション）
十月から十二月は準備期間です。教材1から順に公開し、教材2と教材3も十二月までに公開する予定です。各自のペースで教材を見ながら、AIで改善したい自分の仕事を考えます。工数や期間、品質のうち、何が変われば改善と言えるかも、考えてみてください。

十二月中にワークショップへの参加を受け付け、一月から三月の三か月で実践します。定員は十五名から二十名で、先着順です。自分の仕事に合うスキルを作り、エージェントで使います。

スキルができたら、実際の仕事で使ってみます。結果が目的や要件に合っているか、確認や修正にかかる手間がどう変わったかを確かめ、スキルの観点や手順を改善します。自分だけで使うか、チームでも使うかは、目的に合わせて考えます。

三月の最終共有会では、作ったスキルと、実際に使って何が変わったかを共有します。作れたことだけで終わらず、最初に決めた改善ができたかを、確認や修正の内容も含めて振り返ります。

この実践を進めるために、利用環境と、運営に質問や相談ができる体制を用意します。
