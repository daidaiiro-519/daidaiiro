# 5枚目／全14枚

## 見出し
作れる成果物が増えたとき、確認と修正はどうなりますか？

## 導入文
AIが作った成果物も、人が元の情報や要件と照合してから、仕事で使います。

## 原稿（ナレーション）
AIが作った成果物も、そのまま仕事で使えるとは限りません。資料なら、元の情報と合っているか、仕事に必要な内容が含まれているか。開発なら、設計書やコード、テストが、要件や仕様を満たしているか。さらに、成果物どうしで内容が食い違っていないか。こうした点を確認します。

不足があれば修正し、修正した内容をもう一度確認します。

AIで作成しやすくなると、資料のページ数やコードの量に加え、成果物の種類や数が増えることもあります。その分、読んで、元の情報や要件と照合する対象も増えます。作成の時間が短くなっても、確認と修正の時間が、同じように減るとは限りません。

必要なレビューやテストは、これからも欠かせません。そのうえで、確認の負担を考えるには、成果物の量だけでなく、その内容と示し方にも目を向ける必要があります。

## 前の枚の原稿の結び
では、作れる成果物が増えたとき、それを確認する作業はどうなるでしょうか。
