# 14枚目　受講者（Haiku 5.5）レビュー

## 読み取れたこと
- 業務のAI活用は、成果物を速く作るだけでなく、確認と修正まで含めた仕事全体の生産性と品質を高めることが目的だと読めた。教材1〜3はその流れに沿って並んでいる。

## 図で分かりにくかったところ
- 教材1〜3のカードが矢印で左から右へつながっており、「順に進む手順」に見える。原稿は三つを「学ぶ内容」として並べているので、教材（学習の単位）と工程（作業の順）のどちらか判別しにくい。
- 赤い円「仕事全体の生産性と品質を高める」が結果なのか目標なのかが、矢印の終点だけでは分からない。
- 「Skills」「Agent」が教材3の小さな文字に入っており、初見の受講者には何を指すのか図からは読めない。

## 図と原稿が合っていないところ
- 原稿は「確認や修正」「工数や期間」に触れているが、図にはそれらの語が出ていない。「品質」は赤い円にあるが、確認と修正の変化を測るという原稿の要点は図から消えている。
- 教材2のカードは「業務のルールと設計の対応を確かめる」「対象・判断・関係と守る条件」と書いているが、原稿は「業務をモデルに表し、設計へつなげること」だけで、ルールや守る条件には触れていない。
- 教材1のカードの「範囲」は原稿にない。原稿は「何を実現し、どんな要件を満たすか」のみ。
- 原稿の「経費精算システムの刷新案件」は図にない（次の動画の見出しには出るが、この枚の図には無い）。

## 日本語として不自然・読みにくい表現
- 「対象・判断・関係と守る条件」（教材2の見出し）：名詞の並列だけで、何が何を守るのか読み取れない。
- 「Skillsにまとめ、Agentで使う」：英語と日本語の混在。原稿の「エージェントを使った」と語が揃っていない（Agent と エージェント）。
- 「AIを、仕事全体の生産性と品質の改善につなげましょう」（見出し）と、赤い円の「生産性と品質を高める」で言い方が二通りになっている。

## 意味が分からない語・初めて見る語
- Skills（スキル）と Agent（エージェント）：この枚では説明がなく、次の枚以降で説明される前提に見える。
- 業務のモデル化：何をどの形で表すのか分からない。
- 守る条件、要件：どんな条件・要件を指すのか、この枚の中では例がない。
- 工数：読めるが、この枚の文脈では何を数えるのか不明。

## 前後の枚とのつながりで引っかかったこと
- 前の枚の結びは「このワークショップで身につけたいことを振り返りましょう」だが、この枚は「目指すのは……」と始まり、振り返りの話とは続きが少し違う。
- 導入文「教材を見る前に、自分の仕事のどこを改善したいかを考えてみてください」は、この枚の冒頭と結びで二回繰り返される。二回目は読み上げで聞くと繰り返しに感じる。
- 次の枚「はじめに」の見出しの説明は、図の「共通の題材と、教材1〜3の学習の流れ」と原稿の「経費精算システムの刷新案件」で書き方が違う。

## 自分で補った前提
- 教材1〜3は動画の学習単位で、教材3の後に実際の作業（スキル作成と実践）が来ると補った。
- 赤い円は三つの教材の結果だと補った。
- 矢印は「教材1→2→3の順に進む」を意味すると補った。
- 「工数・期間・品質・確認・修正」は、受講者が自分の仕事で測るものだと補った（原稿の「皆さん自身の仕事で試します」から推測）。

## 受講者として知りたいと思ったこと
- Skills と Agent は何で、どう違うのか（次の枚で説明されるかどうか）。
- 「確認や修正が変わったか」はどう測るのか。工数と品質の基準は何か。
- 「業務のモデル化」「守る条件」の具体例（経費精算システムの例で示されるか）。
- 三つの教材は、ワークショップの当日にどう並ぶのか。
