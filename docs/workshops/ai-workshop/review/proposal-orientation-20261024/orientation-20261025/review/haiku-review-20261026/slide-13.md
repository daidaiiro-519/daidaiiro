# 13枚目　受講者（Haiku 5.5）レビュー

## 読み取れたこと
- 支援は「学ぶ場所（ナレッジ共有ポータル）」「相談する場所（Teams）」「実践に使う環境（Kiro と AWS）」の三つで、困ったら Teams で運営に相談できる、と読めた。
- 「実践の参加者（15〜20名）」に限ってアカウントを発行する、という話だと理解した。

## 図で分かりにくかったところ
- 三つ目の柱「実践に使う環境」が図の本体に無く、下部の1行の注記（モニターのアイコン付き）だけで示されている。三つに分けると言いながら図は二つしか描いていない。
- 矢印の向きが読みにくい。ポータルから「参加者」と「運営」の両方へ矢印が出ているが、運営がポータルを「見る」のか「載せる」のかが分からない。Teams の矢印は参加者と運営の両方へ向いており、「参加者から運営へ質問が届く」向きが描かれていない。
- 「運営」が誰かを示す表示が無い（人型アイコンの下の二文字だけ）。講師か事務局かが分からない。

## 図と原稿が合っていないところ
- 原稿は「三つ」と言うが、図は二つの箱と一つの注記。「実践に使う環境」の箱が無い。
- 原稿は「参加者には、Kiroのアカウントと、AWS環境を発行します」と全参加者に読める書き方だが、図の注記は「実践の参加者（15〜20名）」に限っている。範囲が食い違う。
- 原稿の「相談の要点もTeamsに記録し」は図に無い（本枚では省いてよい内容か判断できない）。

## 日本語として不自然・読みにくい表現
- 「支援は、学ぶ場所、相談する場所、実践に使う環境の三つに分けています。」：「分けています」より「三つあります」の方が自然で、主語も曖昧。
- 「相談のために資料を作る必要はなく、…」（導入文）と「相談のために資料を作る必要はありません。」（原稿）が同じ枚で二回出て、冗長。
- 「相談の要点もTeamsに記録し、あとから確認できるようにします。」：誰が、どの形で記録するかが読み取れない。
- 「参加者には、Kiroのアカウントと、AWS環境を発行します。ポータルのアカウントとは別に用意するものです。」：「発行」と「用意」が混在し、「用意するもの」が何を指すか分かりにくい。
- 「話しながら確認した方がよい場合は、日程を決めて相談の場を設けます。」：「相談の場」が相談会なのか会議なのか、やや硬い。

## 意味が分からない語・初めて見る語
- 「ナレッジ共有ポータル」：「ナレッジ」が外来語で、ポータルが何のサイトか（社内 Web か、どこへ行くか）が分からない。
- 「Teams」：社内の Microsoft Teams だと推測した（補足なし）。
- 「Kiro」：「AIツールのKiro」と原稿にあるが、何ができるツールかの説明は無い。
- 「AWS環境」「AWSの実行環境」：AWS が何かの説明が無い（Amazon Web Services と推測した）。
- 「運営」：誰を指すか説明が無い。
- 「ポータルのアカウント」：ログイン用か、何のアカウントか分からない。

## 前後の枚とのつながりで引っかかったこと
- 前の枚の結び「利用環境と、運営に質問や相談ができる体制を用意します」とは良くつながっている。
- 本枚の末尾「最後に、このワークショップで身につけたいことを振り返りましょう」は、振り返りが本枚の中で行われるのか次枚で行われるのか分からない。図にも対応が無い。
- 次枚の見出し「AIを、仕事全体の生産性と品質の改善につなげましょう」は、本枚の「実践を進める」からの飛躍に感じた。振り返りの予告との関係も見えない。

## 自分で補った前提
- 「運営」は講師か事務局と推測した（原稿・図に説明が無い）。
- 「Teams」は社内の Microsoft Teams、「相談会」はオンラインの場と推測した。
- 「AWS」は Amazon Web Services、「ナレッジ共有ポータル」は社内の Web サイトと推測した。
- 「実践の参加者（15〜20名）」の制限は、原稿の「参加者」を全員と読むのではなく、図の注記に合わせて限定された人たちだけと読んだ。

## 受講者として知りたいと思ったこと
- 運営は誰か。困ったとき、誰にどこで聞けばよいか（Teams のどの場所に投稿するか）。
- ポータルの場所とログインの方法。ポータルのアカウントは、いつ、誰から届くのか。
- 実践の参加者はどう選ばれるか。選ばれなかった人はどう関わるか。
- Kiro と AWS 環境はいつから使え、どのくらいの期間使えるのか。費用はかからないのか。
- 相談会の日程はいつ、どうやって決まるのか。
