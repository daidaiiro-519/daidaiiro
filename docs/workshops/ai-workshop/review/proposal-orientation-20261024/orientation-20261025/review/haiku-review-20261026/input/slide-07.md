# 7枚目／全14枚

## 見出し
AgentがSkillsを使って作業し、人が確かめて改善する

## 導入文
作業の目的と確かめるべき点を、AIが作業のたびに使える形にします。

## 原稿（ナレーション）
前の枚で考えた、何のために、何を作り、何を確かめるのか。これを、AIが作業のたびに使える形にまとめたものが、スキルです。何を参照し、どう判断し、何を確かめるかという、判断の観点と手順を含めます。

エージェントは、作業を進めるAIです。スキルと、その作業に必要な情報を使って、成果物を作ります。必要な情報とは、例えば資料の元になる情報や、開発の要件と仕様、今回の変更点です。図の成果物は例で、毎回すべてを作るのではなく、その仕事に必要なものを作ります。

エージェントは、作った成果物を、スキルの観点で元の情報や要件と照合することもできます。そのうえで人が、根拠と結果を確認して使います。目的や要件に合わないところがあれば成果物を修正し、必要に応じてスキルの観点や手順も改善します。

同じ種類の作業では、同じスキルを使い、そのときに必要な情報や変更点を伝えます。目的や条件が変われば、スキルも見直します。毎回すべてを説明し直すのではなく、使いながら改善していきます。

こうしたAIの使い方を自分の仕事で実現するために、三つの教材で順に学びます。

では、何のために、何をどこまで作り、何を確かめればよいのか。皆さん自身が説明し、AIにも伝えられるでしょうか。
