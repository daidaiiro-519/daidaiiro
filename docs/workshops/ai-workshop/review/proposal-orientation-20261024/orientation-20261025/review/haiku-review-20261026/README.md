- 受講者の設定：開発部門のメンバー（開発者またはPM・PL）。AIは業務で使っているが、AgentやSkillsを整えた経験はほとんどない。参考書籍は読んでいない。

回答は slide-01.md〜slide-14.md。14件とも、指定した8つの見出しの順に答えていることを確認した。

## 採らない指摘

| 指摘 | 理由 |
|---|---|
| 図はAgent・Skills、原稿はエージェント・スキルで表記が揺れる（多数） | 原稿は音声用の読みで書く決まり（共通制作ガイド）。音声では図の語と同じに聞こえる |
| 前の枚・次の枚で説明されているか分からない（多数） | 1枚だけを渡したことによる指摘。用語の初出の問題だけは全体の問題として採った |
| 5枚目：成果物どうしの食い違いが図にない | 右の見出し「元の情報や仕様、成果物どうしを照合する」にある |
| 13枚目：環境が箱になっていない、運営・Teams・AWSの説明がない | 環境は下段の帯で示す。運営・Teams・AWSは社内で通じる運営上の名前 |
| 12枚目：教材2・3の公開時期が図（11月）と原稿（12月まで）で違う | 図は公開の開始、原稿は公開を終える時期を示しており、矛盾しない |
| 2枚目：「位置づけ」の語と中身がずれる | 利用者が選んだ元の図の構成と見出しのため維持する |
| 書籍・工数・照合の具体例がほしい、など | オリエンテーションの役割を超える。具体は共通の「はじめに」と教材で扱う |

## 採った指摘

| 枚 | 指摘 | 修正 |
|---|---|---|
| 全体 | Agent・Skillsを7枚目まで定義せずに使っている | 初出の2枚目の原稿に、スキルとエージェントの定義を一文ずつ入れた |
