# 4枚目／全14枚

## 見出し
あなたの仕事のどこでAIを使い、作業はどう変わりましたか？

## 導入文
人が整理して書いていた作業の一部を、AIが担うようになりました。

## 原稿（ナレーション）
まず、AIを使う前の進め方を思い出してみましょう。図の左は、人が情報を整理し、文章にして、計画書や説明資料、報告資料を作る例です。開発でも、要件をもとに設計書を書き、コードやテストを作成していました。

右は、その作成の一部をAIが担う例です。一つの案を作るだけでなく、複数の案を比較したり、関連する資料を追加したりすることも、以前より手軽になりました。重ねた資料は、同じ時間で作れる案や資料の数が増えたことを表しています。

皆さんの仕事では、どの作業でAIを使っているでしょうか。資料の案を作ったり、設計や実装の方法を試したりしやすくなっていませんか。

では、作れる成果物が増えたとき、それを確認する作業はどうなるでしょうか。

## 前の枚の原稿の結び
まず、普段の仕事のどこでAIを使い、作業がどう変わったかを見てみましょう。
