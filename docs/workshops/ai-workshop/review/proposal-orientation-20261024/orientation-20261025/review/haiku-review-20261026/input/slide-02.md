# 2枚目／全14枚

## 見出し
AIを仕事の改善につなげる考え方を学び、実践するワークショップです

## 導入文
三つの教材で考え方とAgents・Skillsの使い方を学び、自分の仕事で試して改善します。

## 原稿（ナレーション）
AIを使うことで、これまで自分では難しかったことも、実現できるようになってきました。この力を、自分の仕事の改善に活かすために、このワークショップを企画しました。

ワークショップでは、まず三つの教材で、目的と要件の明確化、業務のモデル化と設計、AI活用の実践と改善を学びます。それぞれの内容は、このあと詳しくご紹介します。

そして、学んだことを自分の仕事で実践します。判断の観点と手順をスキルにまとめ、エージェントで作業を進め、結果を確かめて改善します。

目指すのは、自分の仕事に合ったスキルを作り、エージェントを使って作業を進められるようになることです。

では、なぜこうした考え方が必要なのでしょうか。まず、AIで作りやすくなったことが、仕事全体にどう表れているかを考えてみましょう。

## 前の枚の原稿の結び
まず、このワークショップを開く背景と、目指すことからご紹介します。

## 次の枚の見出し
AIで資料やアプリを作りやすくなりました。仕事全体の生産性と品質は、どう変わりましたか？
