# AIを仕事の改善につなげる考え方を学び、実践するワークショップです

AIを使うことで、これまで自分では難しかったことも、実現できるようになってきました。この力を、自分の仕事の改善に活かすために、このワークショップを企画しました。

ワークショップでは、まず教材で考え方を学びます。一つは、何を実現し、どんな条件を満たせばよいかを明確にする考え方です。もう一つは、業務で扱う対象や判断、その関係をモデルに表し、設計につなげる考え方です。

次に、学んだ考え方をAIで実践します。作業の中で何を確かめ、どの順に進めるか。この判断の観点と手順を、スキルとしてまとめます。エージェントは、そのスキルを使って作業を進めます。人は結果を確かめ、合わないところがあれば、スキルや進め方を直していきます。

目指すのは、自分の仕事に合ったスキルを作り、エージェントを使って仕事を進められるようになることです。

では、なぜこうした考え方が必要なのでしょうか。まず、AIで作りやすくなったことが、仕事全体にどう表れているかを考えてみましょう。
