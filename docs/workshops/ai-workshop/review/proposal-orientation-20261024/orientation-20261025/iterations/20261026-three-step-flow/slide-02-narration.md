# AIを仕事の改善につなげる考え方を学び、実践するワークショップです

このワークショップは、AIを仕事の改善につなげる考え方を学び、自分の業務で実践する場です。図の流れで進めます。

まず、教材で考え方を学びます。何を実現し、どんな条件を満たす必要があるのかを明確にする考え方と、業務の対象や判断、関係をモデルに表して、設計へつなげる考え方です。

次に、学んだ考え方をスキルにまとめます。作業の中で何を確かめ、どう進めるかという、判断の観点と手順です。そして自分の業務で、エージェントがスキルを使って作業を進めます。人がその結果を確かめ、合わないところがあれば、スキルや進め方を改善します。

目指すのは、学んだ考え方をスキルにまとめ、エージェントを使って自分の仕事を進められるようになることです。

では、なぜこうした考え方が必要なのでしょうか。まず、AIで作りやすくなったことが、仕事全体にどう表れているかを考えてみましょう。
