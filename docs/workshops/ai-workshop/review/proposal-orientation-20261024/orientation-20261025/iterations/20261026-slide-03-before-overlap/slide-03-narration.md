# AIで資料やアプリを作りやすくなりました。仕事全体の生産性と品質は、どう変わりましたか？

資料やツール、アプリなどを、以前より手軽に作れるようになりました。作成にかかる時間が短くなっただけでなく、これまで自分では作れなかったものも試せるようになっています。皆さんにも、こうした実感があるのではないでしょうか。

ただ、資料やアプリができたあとにも、内容や品質を確かめ、必要なら修正する作業があります。必要な条件を満たして、仕事を終えるところまでが、ここで考えたい仕事全体です。

その全体で見ると、自分の作業を終える工数や、案件を進める期間も短くなっているでしょうか。必要な品質を保てているかも、大切な観点です。

AIで作りやすくなったことを、仕事全体の改善へどうつなげるか。このワークショップでは、その関係を考えていきます。まず、普段の仕事のどこでAIを使い、作業がどう変わったかを振り返ってみましょう。
