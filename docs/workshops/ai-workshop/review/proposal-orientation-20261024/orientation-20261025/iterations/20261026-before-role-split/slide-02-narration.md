# AIを仕事の改善につなげる考え方を学び、実践するワークショップです

AIを使うことで、資料やツールを以前より作りやすくなり、これまで難しかったことも実現できるようになってきました。この力を、必要な品質を満たし、仕事全体を効率よく進めるためにも活かしたいと考えています。

今回のワークショップは、そのための考え方を学び、自分の業務で試す場です。教材では、何を実現したいのか、どんな条件を満たす必要があるのかを明確にし、業務を理解して設計へつなげる考え方を学びます。そして、エージェントやスキルを使い、学んだ考え方をAIの作業で実践します。

自分の業務で試した結果を確かめ、改善するところまで経験していきます。成果物を速く作ることに加えて、必要な品質を満たし、確認や修正まで含む仕事全体を改善できるようになることを目指します。

まず、AIによって作りやすくなったことと、仕事全体の生産性との関係を、皆さんの仕事に照らして考えてみましょう。
