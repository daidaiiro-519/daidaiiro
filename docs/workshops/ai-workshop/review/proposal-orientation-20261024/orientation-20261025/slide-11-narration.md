# 教材動画や解説記事、活用事例をポータルで見られます

教材は、社内のナレッジ共有ポータルで公開します。教材動画や解説記事、AIの活用事例などを、一か所で見られる場所です。

教材は、教材1から順に学びます。前の教材の内容を次の教材の前提にしますので、分からないところは、前の教材に戻って確認できます。

ポータルには、参加者が作ったスキルと、その記録も掲載する予定です。何のために作ったか、どんな判断の観点と手順をまとめたか、どう使い、試してどうだったかを、あわせて確認できるようにします。カテゴリやタグから、自分の仕事に関係するものを探せます。

今期は、ワークショップの参加者と、教材の閲覧を希望する方を対象としたトライアルです。閲覧希望は事前アンケートで確認し、ポータルのアカウントを発行する予定です。

この教材で学び、自分の仕事で試す期間を、次の日程で予定しています。
