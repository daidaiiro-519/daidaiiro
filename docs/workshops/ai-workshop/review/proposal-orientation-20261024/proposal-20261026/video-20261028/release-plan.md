# 企画書の音声・字幕付き動画

ACDR 0209 で正本にした企画書の詳細版から、本編29枚（表紙〜まとめ）を動画にする。原稿は発表原稿の本編を1文字も変えずに使う。付録9枚は質疑で使う枚なので、動画に含めない。

## 生成した条件

| 項目 | 内容 |
|---|---|
| 原稿 | 正本の build_deck.py の本編29枚の原稿。発表原稿 speaker-notes.md の 01〜29 と一致する |
| 枚の識別子 | build_deck.py の枚のラベル（表紙 ・ 本日の内容 ・ … ・ まとめ） |
| 音声 | slide-deck-speech で合成。声は Takumi、エンジンは neural。キャッシュは narration/cache-proposal-v1 |
| 読み辞書 | Polly の aiworkshop。教材と共用の lexicon.pls に3語を足した（下の表） |
| 画像 | 正本の out/director-deck.html を1枚ずつ 1280×720 で撮った previews/01.png〜29.png。動画では使えない「矢印キーでめくる」の案内だけ消し、枚番号は PDF と同じ番号のまま残す |
| 動画 | 教材の build_videos.py の条件（FFmpeg のイメージ ・ 画面サイズ ・ 字幕の帯 ・ 書体 ・ 字幕の組み方）を読み込んで使う。枚の前に0.25秒、後に0.35秒の間を置き、0.25秒のフェードで切り替える |
| 音声のみ | 動画の音声を 128kbps ・ 48kHz の MP3 へ書き出した |
| ポスター | 表紙の画像 previews/01.png |

## 読み辞書に足した語

| 語 | 読み | なぜ |
|---|---|---|
| SIer | エスアイヤー | 背景の枚で読む。既定の読みでは英語の綴りとして読まれるおそれがある |
| GitHub | ギットハブ | ポータルの設計の枚で読む。製品名の読みに合わせる |
| Confluence | コンフルエンス | ポータルの設計の枚で読む。製品名の読みに合わせる |

Teams は足さない。オリエンテーションの音声が既定の読みで合成済みで、辞書へ足すと、同じ語の読みが動画によって違うおそれがある。

## 検証の結果

| 項目 | 結果 |
|---|---|
| 枚数と並び | 29枚。動画の枚の並び、合成した音声の並び、原稿の並びが一致する |
| 原稿 | 音声の入力の文が、発表原稿の本編29枚と1文字も違わない |
| 長さ | 動画 2467.3秒（約41分07秒）、音声のみ 2467.3秒 |
| 形式 | 1280×816（スライド720＋字幕の帯96）、映像 H.264、音声 AAC |
| 字幕 | 494件。すべて動画の長さの中にあり、重ならず、2行以内 |
| 全編のデコード | エラーなし |
| 映像と元のスライド | 各枚の読み上げ開始から2.5秒後のフレームと元の画像の差（RMS）が最大 1.99 で、基準の8未満 |
| 目視 | 29枚のフレームで、字幕がスライドの下の帯に収まり、図を隠さないことを確認した |

全音声の聴取と、全494件の字幕の目視はしていない。
