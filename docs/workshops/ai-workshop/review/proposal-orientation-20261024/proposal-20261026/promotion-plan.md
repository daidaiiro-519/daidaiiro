# 企画書の正式反映

利用者が2026年10月26日から28日にかけて、詳細版の全38枚を1枚ずつ確認した版を、正本へ反映する。対象は企画書（詳細版と要点版）のスライドと発表原稿、アンケート・効果測定案、Formsの作成用プロンプトである。オリエンテーション、共通の「はじめに」、教材本編は含まない。

現行の正本は、旧い到達像（目的を言葉にしてAIに伝え、達成する）、旧教材名（目的の把握・言葉の定義・仕組みの構築）、定員15名のままである。確認済みの版は、共通方針revision 2026-10-25-13と、正式版のオリエンテーション（ACDR 0207）に合わせ、AIの活用を仕事全体の生産性と品質の改善につなげる到達点と、三教材の新しい役割を説明する。

## 反映する差分

| 対象 | 理由 |
|---|---|
| `docs/workshops/ai-workshop/proposal/src/build_deck.py` | 全枚の見出し・導入文・原稿と並びを、利用者が確認した版に改める。「この企画の本質」を外し、目的の枚を背景の次へ移す。定員を15〜20名、Kiroの費用を月 $300〜$400 にする。回答フォームの枚を、スマホ幅の画面のワイヤーフレーム4枚と、KPIと設問・設問の見直しの枚にまとめる |
| `docs/workshops/ai-workshop/proposal/src/visuals.py` | 各枚の図を、確認した版に改める。オリエンテーションが読み込む portal() と support() は変えず、企画書用に portal_proposal() と support_proposal() を加える。回答フォームのワイヤーフレームを描く部品を加える |
| `docs/workshops/ai-workshop/proposal/src/survey.json` | KPIに対応しない問いを外し、事前7問・参加時は改善1件で8問にする。尺度は全段階に言葉を付け、「わからない」を尺度の外に置く。各フォームの冒頭の説明文を持たせる |
| `docs/workshops/ai-workshop/proposal/src/build_survey_docs.py` | アンケート・効果測定案とFormsの作成用プロンプトの本文を、新しいKPIと設問、答えやすさの方針に合わせる |
| `docs/workshops/ai-workshop/proposal/out/` のスライド・原稿・設計書・PDF・一覧画像 | 上の生成元から生成した成果物。利用者が比較ページで確認したスライドと、書籍の表紙の参照方法を除いて一致する |

## 変えないもの

オリエンテーション（lesson-00-start）、共通の「はじめに」（lesson-01-lead）、教材1（lesson-02〜06）、教材2（ddd-00・02・09）は、企画書の生成元の部品を読み込んでいる。変更後の生成元で生成し直しても、14本すべての出力が1バイトも変わらないことを確認した。

運営設計案（`proposal/out/workshop-plan.md`）は手で書いた文書で、今回の確認の対象に含めていない。旧教材名と旧い到達像が残っているため、別に見直す。

## 確認

| 確認 | 結果 |
|---|---|
| 確認済みの版との一致 | 作業コピーの生成元から正本と同じ名前で生成したスライドが、利用者が確認したスライドと、書籍の表紙の参照方法を除いて一致する |
| 語の検査 | 教材の語の決まりで、変更前に無かった該当が無い |
| 文書の検査 | アンケート・効果測定案とFormsの作成用プロンプトは、ゲート1を通る |
| 料金 | Kiro Proの料金と超過の扱いを、2026-10-27に公式の料金ページの原文と照合した |
| 他の教材への影響 | 上の「変えないもの」のとおり |
