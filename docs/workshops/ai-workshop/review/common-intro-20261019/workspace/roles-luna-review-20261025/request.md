# 今回の受講者Lunaへの確認依頼

利用者が、各役割のAI活用という観点で「はじめに」をLunaに読ませ、フィードバックを得るよう依頼した。モデルはgpt-6-luna、過去のレビューや会話を引き継がない新しい受講者役で確認する。

入力は表紙と本文8枚の全9枚の画像、および全ナレーション。01.pngが表紙、02〜09.pngが本文1〜8に対応する。presentation.htmlとsources/に確認時点の入力を固定し、manifest.jsonにハッシュを記録した。動画や音声そのものは今回の確認対象ではない。

## 確認すること

- 開発者、PM・PL、業務担当者が、それぞれ何を学び、自分のAI活用にどう関係するか理解できるか。
- PM・PLが開発成果物の確認者としてだけ描かれていないか。自身の作業でAIを使う場面まで想像できるか。
- 表紙、事例、三教材の紹介というストーリーが通るか。
- 目的・要件、業務モデル・設計、AI活用の実践と改善の違いと接続が理解できるか。
- 図や言葉が理解しにくい箇所、情報量が多すぎる箇所、各役割の実務として不自然な箇所はどこか。
- 全職種が全工程を同じ深さで学ぶように見えないか。

資料から理解したこと、自分で補った前提、分からないことを分けて記録する。指摘には閲覧番号と本文番号、実際の文言、理由、重大度を添える。感想と改善案も区別する。レビュー担当は図と原稿を変更しない。

これは受講者役の理解確認であり、専門的な妥当性の判定、利用者の承認、正本への適用判断ではない。指摘を受けた段階では採否を未決定とし、今回の依頼では教材を自動修正しない。
