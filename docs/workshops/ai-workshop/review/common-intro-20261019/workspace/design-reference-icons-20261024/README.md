# 人物・成果物・動作を線画で示した共通導入6枚目

利用者が2026年10月24日に確認し、今後も継続するよう求めたデザインの例。目的・要件・開発作業の所属を保ち、対象や動作を線画と短いラベルで区別できるようにした。

- 申請者と開発者は、人物の位置と所属する枠で区別する。
- 申請書と証憑は異なる書類の線画で示す。申請内容の修正にはペンを添える。
- 承認を維持する状態は人物とチェック、証憑を確認し直す動作は人物・証憑・戻る矢印で示す。
- 要件確認、設計・実装・テスト、レビューにも、書類・コード・チェックの線画を使用する。
- 対象や動作の説明文を短くし、目的や業務条件、要件の意味は言葉で残す。
