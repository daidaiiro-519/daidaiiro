# 比較ページの操作と差分表示の改善

スライドと原稿の内容は変えず、比較ページの操作と表示を修正した。スライド入力JSONとSVGは、変更前のコミットと同じ内容である。

## 変更したこと

資料とスライドの選択、前後移動、現在の枚数を上部にまとめた。スライド比較、原稿差分、変更理由、構成と進捗、資料一覧へ移動できる。原稿を読み終えた位置にも前後移動を置き、選択した資料と枚をURLへ記録して再表示できるようにした。

図は並列表示と重ね合わせを切り替える。原稿は見出し、導入文、ナレーションごとに、変更前と変更後を並べ、追加と削除を文単位で示す。日本語の文字単位の比較では無関係な文の一文字が対応し、文章が分断されるため、文単位へ変更した。強調なしの全文表示にも切り替えられる。変更理由は独立した領域で常時示す。

過去の案と参考資料、構成案は開閉できる領域へ移した。旧原稿が保存されていない資料は、原稿差分を推測で作らず、変更後のみ表示することを明記する。変更理由がない枚も、未記録と表示する。

## 入力と生成元

build_review.pyが比較ページのデータを作り、review_ui.pyがreview-ui-shell.html、review-ui.css、review-ui.jsを適用する。原稿差分は保存されたbeforeNotesとafterNotesから生成する。表示用HTMLだけを直接直さない。

配色は既存ページのwarm-paperの変数を参照し、新しい色の値は追加していない。参考にしたUXの判断基準は、task-flow-analysis、visibility-of-system-status、recognition-rather-than-recall、consistency-and-standardsである。いずれもux-advisorのgetで読んだ。利用者による使いやすさの評価を済ませたという意味ではない。

## 確認

check_review_ui_20261024.cjsで、直接リンクの5枚目の選択、原稿の変更前後が元の全文と一致すること、変更なしの表示、表示モード切替、重ね合わせとキーボード操作、資料と枚の切替、URL再読込、構成案への移動、390px幅の横はみ出しなし、JavaScriptエラーなしを確認した。旧原稿がない資料の差分を作らないことも確認した。

既存のcheck_intro_comparison_20261018.cjsでも、図と原稿の連動と切替を確認した。desktop.png、script-diff.png、overlay.png、mobile.png、mobile-script.pngを描画し、見た目を確認した。音声・動画は変更していない。

## 文書の10判定

1. 対象：スライド内容の修正と、比較ページの操作変更を区別した。
2. 型：比較対象は同じ並び、変更理由は別領域で示した。
3. 数：見出し・導入文・原稿の三項目に分けた。
4. 見出し：図、原稿、変更理由、構成の移動先を名前で示した。
5. 結論：何を選び、どの差分を確認できるかをページ冒頭に示した。
6. 対応：変更前は左、変更後は右とし、図と原稿の並びを一致させた。重ね合わせ時の左右は説明文と範囲の表示で明記した。
7. 用語：追加、削除、変更なし、未記録を区別した。
8. 読み手：生成処理の名前は確認用記録に置き、比較する利用者の操作欄には出していない。
9. 量：過去の案と参考資料を開閉し、現在の確認を先に置いた。
10. 比喩：新しい比喩や造語を使用しなかった。
