# 経費精算システムの刷新に、新しい開発者が加わりました

既存の仕様書とコードをもとに、チームでAIを活用して開発を進める架空の案件です。

ここからは、三つの教材で共通して使う題材を紹介します。経費精算システムを刷新する、架空の案件です。

図の左には、この案件のチームを示しています。既存システムを知るメンバーに、新しく開発者が加わりました。開発担当者のほかに、経費精算の業務を知る担当者と、案件を管理するプロジェクトマネージャーやプロジェクトリーダーがいます。

右にある仕様書、既存コード、開発手順は、このチームが参照する資料です。新しく加わった開発者も、それらを確認しながら作業を進めます。

この案件では、実装だけでなく、レビューやテストにもAIを活用します。AIが作ったものを開発者自身が確認し、ほかの担当者もレビューやテストを行います。

教材では、このチームの作業を追いながら、AIを使った開発をどのように進めるかを考えます。まず、新しく加わった開発者が担当する機能を見てみましょう。
