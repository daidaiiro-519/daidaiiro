# 画面遷移とメイン画面の整理

利用者はdesign-review.htmlの画面遷移図と、それに基づくメイン画面からの導線整理を依頼した。スライドと原稿の入力は変更していない。

## 画面の役割

| 画面 | 目的 |
|---|---|
| index.html | 比較、通しの閲覧、制作情報の三つから作業を選ぶ。資料名からも移動できる。 |
| design-review.html | 選んだ資料と枚の図、原稿差分、変更理由を確認する。並列・重ね合わせ、原稿の差分・全文は同じ画面内の切替。 |
| materials.html | スライドと原稿を通して読み、動画・音声を確認する。変更前の動画は注記して区別する。 |
| workflow.html | 共通方針、担当別進捗、制作手順、変更記録を参照する。 |
| navigation.html | 実装した画面遷移図と、確認する順序を見る。SVGとMermaidのソースを持つ。 |

比較と閲覧の往復では資料と枚を引き継ぐ。閲覧画面では、選んだ枚と表示モードをURLにも記録する。各画面からメインへ戻れる。拡大・PDF・原稿ファイルは別タブで表示する。

旧メイン画面の資料閲覧機能はmaterials.htmlへ残した。従来のルートの#lead、#orientation、#brief、#detailは同じ閲覧先へ移動する。従来のdesign-review.html?slide=5#leadも利用できる。

## 生成元

build_review.py --publishが、比較ページに加えreview_navigation.pyからメイン・閲覧・制作情報・画面遷移図を生成する。閲覧の元の入力はmaterials-source.html。はじめにの閲覧には、現在のslide-NN.jsonとafter.htmlを使い、変更前の動画とは分けた。

共通方針と担当情報はreview/shared/から、はじめにの進捗は既存のprogress.jsonから読む。公開HTMLの手修正は再生成で失われる。進捗や共有方針の変更を画面に出す場合も再生成する。新しいサーバーや別ポートは追加せず、8772番ポートを使う。

画面遷移図はnavigation.source.svgを既存のtheme.jsonで解決した。新しい配色値は追加していない。静的なSVGと、Mermaidのnavigation.mmdを保存した。

## 確認

check_review_navigation_20261024.cjsで、メインの三つの作業、比較から閲覧へ同じ資料と枚で進み比較へ戻ること、閲覧後の再読込、オリエンテーション動画への直接移動、共有方針と進捗、旧リンク、390px幅で横はみ出しがないこと、JavaScriptエラーがないことを確認した。

check_review_ui_20261024.cjsでも、既存の図と原稿の差分・表示方法・キーボード操作が動くことを確認した。主な画面のデスクトップとスマートフォンの画像、遷移図の通常・ダーク設定の画像を保存して目視した。図の検査1〜4も通過した。

## 文書の10判定

1. 対象：ページの移動と、同じ画面内の切替を区別した。
2. 型：遷移は図、各画面の役割は表、操作の順序は番号付き一覧にした。
3. 数：メインの作業は比較、閲覧、制作情報の三つに分けた。
4. 見出し：移動先と画面の見出しの名前を対応させた。
5. 結論：メイン画面から何を選ぶかを最初に示した。
6. 対応：各画面の上部に戻り先と主な移動先を置いた。
7. 用語：変更を確認する操作と資料を通して見る操作を区別した。
8. 読み手：ファイル名は遷移図と作業記録で示し、メインの主な操作は利用者の目的で表現した。
9. 量：過去の画像や技術的な引き継ぎは参考資料から開く。
10. 比喩：新しい比喩や造語で画面名を説明していない。
