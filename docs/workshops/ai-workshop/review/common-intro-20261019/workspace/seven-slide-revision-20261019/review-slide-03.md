# 内容3枚目の確認記録

マージ後CIで承認処理を含むテストを行い、上長承認後も申請を変更できる不具合が発覚する場面を作成した。承認後の制限自体がないという旧設定は使わず、制限を始める状態が違うことを図と原稿に反映した。

| 判定 | 結果 |
|---|---|
| 1 指し先 | 上長承認と経理承認、申請者の直接変更を区別した。 |
| 2 情報の型 | 状態の流れと、本来・実装の制限範囲を図で対比した。 |
| 3 列挙 | 申請・上長承認・経理承認を番号で示した。 |
| 4 見出し | マージ後CIで分かった不具合の内容を明示した。 |
| 5 結論 | 発覚した動作を見出しに置いた。 |
| 6 文調 | ナレーションを敬体にした。 |
| 7 用語 | レビュー承認と業務の承認、作成したテストの通過と必要な確認を区別した。 |
| 8 語彙 | 状態と操作を具体的な既存の用語で説明した。 |
| 9 情報量 | 不具合の現象と修正・再確認を示し、取り違えの過程は次の枚に残した。 |
| 10 比喩 | 金額と保存結果で期待・実際の違いを示した。 |

未適用の判定はない。SVG検査と文書検査は通過した。通常表示・ダーク設定・幅358pxで描画した画像を確認した。単体テストやレビューでも発見可能な不具合であることを原稿に明記した。比較ページで原稿・iframeの見出し・枚の切り替え・スマートフォン幅を確認し、エラーはなかった。正本・音声・動画は未変更である。

## 初級編向けの表現への変更

2026年10月21日、2・3枚目のCI・マージという表記を、変更の取り込み後に動く自動テストという説明へ変更した。上の10の判定を再適用し、図と原稿の対応、前後の接続、用語の意味と情報量を確認した。図の配置と工程は維持した。SVGと原稿の検査は通過し、描画画像を目視した。比較の原稿とiframeも確認した。
