# 複数の業務条件と、一例としての承認

| 判定 | 結果 |
|---|---|
| 1 指し先 | 業務条件全体と、その中の承認状態の維持を区別した。 |
| 2 情報の型 | 複数の条件を同じ枠に含め、取り上げる一例だけを強調した。 |
| 3 列挙 | 必須項目、金額の整合性、承認状態の三つを並べた。 |
| 4 見出し | 教材1で目的から必要な内容を考える主張を維持した。 |
| 5 結論 | 共通の目的を先に置き、必要な条件の例をその下に置いた。 |
| 6 文調 | 原稿は敬体にした。 |
| 7 用語 | 言葉の承認と、業務条件としての承認状態の維持を区別した。 |
| 8 語彙 | 追加した条件は架空案件の具体例として説明した。 |
| 9 情報量 | 三つの条件は短く示し、意味の食い違いの説明は一例に集中した。 |
| 10 比喩 | 条件全体と一例の関係を、枠と強調で直接示した。 |

未適用の判定はない。教材1の全業務条件を承認の話だけに限定しなかった。教材2には、必要な条件の中にも文脈による言葉の意味の食い違いが起きやすいものがあるという問いで接続した。必須項目と金額の整合性は、架空案件の例としてcase-setting.jsonに記録した。SVG・文書の検査は通過し、描画画像を確認した。正本・音声・動画は未変更である。
