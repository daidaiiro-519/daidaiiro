# 内容2枚目の確認記録

AIに条件を伝えて実装・テスト・レビューを進め、短時間でレビュー承認まで到達する場面を図と原稿に反映した。承認段階の取り違えは、この枚では説明しない。

| 判定 | 結果 |
|---|---|
| 1 指し先 | 担当する画面・APIと、AIに伝える条件を上の枠に明示した。 |
| 2 情報の型 | 実装、レビュー、レビュー承認を順番のある図にした。 |
| 3 列挙 | 三つの工程を番号で分けた。 |
| 4 見出し | この枚で起きたことを、実装からレビュー承認までとして明示した。 |
| 5 結論 | 短時間でレビュー承認まで進んだことを見出しに置いた。 |
| 6 文調 | ナレーションは敬体にした。 |
| 7 用語 | 作成した単体テストの通過、レビュー承認、マージを区別した。 |
| 8 語彙 | 既存の開発用語を使い、状態の違いを独自の語で説明しなかった。 |
| 9 情報量 | 二段階の業務承認の詳細と原因は後の枚に残した。 |
| 10 比喩 | 人物・同じ大きさの成果物・工程間の矢印で作業を表した。 |

未適用の判定はない。SVG検査と原稿・構成案の文書検査は通過した。通常表示・ダーク設定・幅358pxで描画した画像を確認し、文字のはみ出しとブラウザーのエラーはなかった。比較は直前の内容2枚目を変更前に使用する。内容3枚目以降はまだ従来版である。正本・音声・動画は未変更である。
