# 内容5枚目の構成の見直し

利用者は、以前の図の型に引かれ、図だけでは理解しづらいと指摘した。往復図をそのまま使う案を外し、目的を先に示したうえで、目的によって確認内容が変わることを直接比較できる図へ変更した。

| 判定 | 結果 |
|---|---|
| 1 指し先 | 左右それぞれに見出しと確認対象を入れ、所属を明確にした。 |
| 2 情報の型 | 共通のレビュー目的を上に置き、現状と目的から考えた確認を左右で比較した。 |
| 3 列挙 | 上下の番号を追う必要をなくした。 |
| 4 見出し | 教材1で何を学ぶかを維持し、図の中で確認内容の違いを示した。 |
| 5 結論 | レビューで実現したいことを最初に置いた。 |
| 6 文調 | ナレーションは敬体にした。 |
| 7 用語 | AIの指摘なしという結果と、業務条件を満たす根拠を区別した。 |
| 8 語彙 | 既存の用語を使用し、図の移動を説明する言葉を削った。 |
| 9 情報量 | 確認対象と必要な対応関係に集中し、目的の大きさは原稿で説明した。 |
| 10 比喩 | 目的に立ち戻ることを、読み取りにくい経路で表す必要をなくした。 |

未適用の判定はない。設計原則に従い、境界・対応・違いを図だけで確認した。AIの指摘確認自体を不要とは説明していない。目的の大きさは用途に合わせるという説明と、教材2への意味の問いは維持した。SVGと文書の検査は通過した。通常表示・ダーク設定・幅358pxの画像を目視した。正本・音声・動画は未変更である。
