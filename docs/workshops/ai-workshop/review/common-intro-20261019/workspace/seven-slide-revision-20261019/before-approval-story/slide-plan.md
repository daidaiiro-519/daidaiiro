# 三教材共通の「はじめに」：7枚構成

今回の比較対象は内容1枚目である。内容2〜7枚目は構成案であり、図と原稿は1枚ずつ確認しながら作成する。比較画面の内容2枚目以降は、まだ従来の10枚構成である。

全体で目指すのは、必要な品質を満たし、開発完了までの時間を短くすることである。教材1では、そのためにAIに任せる作業の目的と必要な内容を考える。教材2では条件を表す言葉の意味と範囲を明確にし、教材3ではAIが実行し、人が確認できる仕組みにする。

## 1　経費精算システムの刷新で、チームとしてAIを活用します

| 項目 | 内容 |
|---|---|
| 伝えること | 既存メンバーと新しい開発者、参照する仕様・コード、AI活用の目的を示す。 |
| 図で示す関係 | 既存の人物・チーム境界・資料アイコンを維持する。下の枠で、品質を満たして開発完了までの時間を短くしたいという目的を示す。 |
| 次へのつながり | どんな作業を、AIでどう進めたのか。 |
| 制作状況 | 今回の確認対象 |

## 2　AIで実装とレビューを進め、短時間でレビュー承認まで到達しました

| 項目 | 内容 |
|---|---|
| 伝えること | 作成とレビュー承認までの速さを示す。まだ開発完了ではない。 |
| 図で示す関係 | 既存画面と刷新する画面・API、同じ大きさで重なるコード・テスト・説明、AIと人のレビューを作業順に配置する。 |
| 次へのつながり | 速く承認された変更は、そのまま完了できたのか。 |
| 制作状況 | 構成案・図は未制作 |

## 3　テストで不具合が発覚し、修正と再確認が必要になりました

| 項目 | 内容 |
|---|---|
| 伝えること | 短時間で承認まで進んでも、修正・再テスト・再レビューが発生し、完了までの時間は期待ほど短くならなかった。 |
| 図で示す関係 | 既存の申請・承認・再変更の図と、期待する金額・実際の金額の対比を使用する。下に修正・再テスト・再レビューの流れを示す。架空の所要時間や数値は作らない。 |
| 次へのつながり | 仕様も確認し、AIと人がレビューしたのに、なぜ見逃したのか。 |
| 制作状況 | 構成案・図は未制作 |

## 4　仕様を確認し、AIと人がレビューしたのに、なぜ見逃したのでしょうか？

| 項目 | 内容 |
|---|---|
| 伝えること | 成果物が増えた一方、業務条件と実装・テストの照合が不十分になり、レビューがAIの指摘確認に偏った事例を振り返る。 |
| 図で示す関係 | 上に増えた成果物とAIの指摘なし。下に既存の業務条件と実装・テストの対応を示し、確認できていなかった条件を区別する。 |
| 次へのつながり | レビューで実現したいことは、指摘の有無を確認することだけなのか。 |
| 制作状況 | 構成案・図は未制作 |

## 5　教材1では、作業の目的から必要な内容を考えます

| 項目 | 内容 |
|---|---|
| 伝えること | レビューを例に、目的から必要な内容を考える。品質と時間短縮は全体の目的であり、教材1だけで解決するとは説明しない。 |
| 図で示す関係 | AIの指摘確認という作業から目的へ戻り、業務条件・実装・テスト結果の確認へ進む往復を、既存の縦方向の図で表す。条件の例として「承認後は変更不可」を示す。 |
| 次へのつながり | 「承認後は変更不可」と伝えれば、何を確かめればよいか分かるのか。 |
| 制作状況 | 構成案・図は未制作 |

## 6　教材2では、条件を表す言葉の意味と範囲を明確にします

| 項目 | 内容 |
|---|---|
| 伝えること | 必要な条件を挙げるだけでなく、その言葉を実装やテストで判断できる説明にする。言葉の曖昧さが今回の唯一の原因だったとは断定しない。 |
| 図で示す関係 | 「承認後は変更不可」を、申請の状態・操作する人・対象データ・画面とAPIの関係へ展開する。回答は仕様や既存コードで確かめ、不明点は業務担当者に確認する。 |
| 次へのつながり | 明確にした条件を、AIの実装・レビュー・テストでどう使うのか。 |
| 制作状況 | 構成案・図は未制作 |

## 7　教材3では、条件と手順をAIが使える仕組みにします

| 項目 | 内容 |
|---|---|
| 伝えること | 目的と条件をAIの作業に反映し、人が結果と根拠を確認する方法を学ぶ。説明の最後は教材1の最初の問いに戻る。 |
| 図で示す関係 | 共通の参照情報から開発・レビュー・テストのAgentとSkillへつながる既存図を使用する。条件と実装・テスト結果の対応を出力し、人が条件の抜けと根拠を確認する。 |
| 次へのつながり | 実装やレビューは何のために行うのか。教材1「目的の把握」から考える。 |
| 制作状況 | 構成案・図は未制作 |
