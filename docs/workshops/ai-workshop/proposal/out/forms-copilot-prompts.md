# Microsoft Forms の Copilot に渡すアンケートのプロンプト

[アンケート・効果測定案](survey-and-evaluation.md) の設問を、Microsoft Forms の Copilot へそのまま貼れる形にしたものである。フォームは事前・中間・終了時の3本である。

## 進め方

Copilot で作るのは事前アンケートだけにする。中間と終了時は、事前のフォームを複製し、後ろの部分だけを差し替える。

| 手順 | 作業 |
|---|---|
| 1 | 事前アンケートのプロンプトを Copilot に貼り、フォームを生成する |
| 2 | 生成結果を設計書と照合し、分岐と設定を手で入れる |
| 3 | 事前のフォームを複製し、中間アンケートの差し替え部分を入れる |
| 4 | 中間のフォームを複製し、終了時アンケートの差し替え部分を入れる |

共通の設問と尺度は、3回とも固定すると設計書で決めている。Copilot に3回生成させると、文言が回ごとに変化する可能性がある。複製にすれば、共通部分の文言と分岐を保持できる。

## 1. 事前アンケート

````
社内のAI活用ワークショップの参加者（約15名）が回答する「事前アンケート」を作成してください。回答時間は8分程度です。クイズ形式や点数は不要です。
以下の設問を、この順番・文言のまま作成してください。設問文と選択肢の言い換え・追加・省略はしないでください。【】はセクションの区切りです。

【セクション1：基本情報と現在の状況】
1. 現在の職種を選んでください。（選択式・1つ・必須）
 選択肢：開発／PM／PL／その他
2. 前回の回答から、または直近で職種の変更がありましたか。（選択式・1つ・必須）
 選択肢：あり／なし
3. 過去4週間に、実務でAIを使った日は何日ありましたか。研修の演習だけに使った日は含めません。（選択式・1つ・必須）
 選択肢：0日／1〜3日／4〜7日／8〜15日／16日以上／実務の機会なし
4. 上の回答に影響した事情があれば記入してください（休暇、業務変更、利用制限など）。（短いテキスト・任意）
5. 次のことが、今どの程度できますか。（リッカート形式・必須）
 行：
 ・AIを使えそうな仕事を思いつけますか。
 ・仕事で困っている理由を整理できますか。
 ・AIに、してほしいことを伝えられますか。
 ・AIに、いくつかの作業をまとめて頼めますか。
 ・作ったものの使い方を、他の人にも分かるように説明できますか。
 ・AIの答えが間違っていないか確認できますか。
 ・他の人からの感想をもとに、作ったものを直せますか。
 列：まだやり方が分からない／やり方は分かるが、まだできない／手助けがあればできる／一人でできる／状況に合わせてやり方を変えられる／試す機会がない
6. 担当している業務を選んでください。（選択式・1つ・必須）
 選択肢：PM・PLの業務のみ／開発の業務のみ／両方／どちらも担当していない

【セクション2：PM・PLの業務】
7. 過去4週間に、次の業務でAIをどの程度使いましたか。（リッカート形式・必須）
 行：
 ・複数資料から情報を集めて集計する
 ・週次・月次報告や予実を可視化する
 ・会議・チャットから課題・担当・期限を整理する
 ・品質・障害・リスクの傾向を分析する
 ・改善案・効果の見込み・提案資料を作る
 ・過去の会議・成果物・トラブル事例を探して再利用する
 列：使っていない／試したが、実務には使っていない／実務で1回使った／実務で複数回使った／この業務を担当していない／担当しているが、この4週間は実施機会がなかった
8. 開発の業務も担当していますか。（選択式・1つ・必須）
 選択肢：はい／いいえ

【セクション3：開発の業務】
9. 過去4週間に、次の業務でAIをどの程度使いましたか。（リッカート形式・必須）
 行：
 ・要求を整理して仕様をまとめる
 ・設計案を作り、選択肢を比較する
 ・コードを作成・修正する
 ・コードや設計をレビューする
 ・テスト項目・テストコードを作り、結果を確認する
 ・ログや不具合を調べ、運用・保守に役立てる
 列：設問7と同じ6つ

【セクション4：困りごとと学びたいこと】
10. 今、AI活用で特に困っていることを選んでください（最大3つ）。（選択式・複数回答・必須）
 選択肢：AIを使う場面が分からない／AIへの頼み方が分からない／AIの結果の確かめ方が分からない／作ったものを他の人と共有できない／使えるツール・環境が整っていない／時間が取れない／特に困っていない／その他
11. 今後、AIを使ってできるようになりたい業務を選んでください（最大2つ。自分が担当する業務から選んでください）。（選択式・複数回答・必須）
 選択肢：設問7と設問9の行の12業務／その他／まだ思いつかない
12. その業務の、どんな場面で困っていますか。一つの場面を短く書いてください。具体的な案件名は不要です。（短いテキスト・任意）
13. どの支援があると、次に進めそうですか（最大2つ）。（選択式・複数回答・必須）
 選択肢：考え方を学ぶ動画／操作の説明／使い方のヒント／ブログ／Teams投稿での相談／会話での相談／使うツールの準備／学習時間／その他

【セクション5：今の仕事】
14. AIを使っている、または使ってみたい仕事を一つ挙げてください。今はどのように進めていますか。（長いテキスト・任意）

【セクション6：個人目標】
15. 誰の、どんな課題ですか。対象者と困っている場面を書いてください。（長いテキスト・必須）
16. どんな仕組みをAIで作りますか。作るものと、使う知識・手順を書いてください。（長いテキスト・必須）
17. 誰に使ってもらいますか。利用者と試す場面を書いてください。（長いテキスト・必須）
18. 何が変われば達成ですか。結果・確認方法・期限を書いてください。（長いテキスト・必須）
````

## 2. 中間アンケート

事前アンケートを複製し、「セクション5：今の仕事」と「セクション6：個人目標」を削除してから、次の設問を追加する。Copilot へ渡す場合も、手で入力する場合も、この文面を使用する。

````
【セクション5：途中の変化】
14. 新しくできるようになったこと、または試したがうまくいかなかったことを一つ挙げてください。入力した情報・出力・確認や修正の方法を教えてください。変化がない場合や、まだ試していない場合も、そのまま書いてください。（長いテキスト・必須）
15. その変化に影響したものは何ですか。教材、相談、実務経験、他の研修、ツールの更新などから教えてください。（長いテキスト・任意）
16. 事前アンケートで書いた個人目標を変更しましたか。変更した場合は、変更後の目標と変更の理由を書いてください。（長いテキスト・任意）
````

## 3. 終了時アンケート

中間アンケートを複製し、設問14・15を残して設問16を削除してから、次の設問を追加する。

````
16. 今後も実務で使いたいものと、まだ支援が必要なことを教えてください。（長いテキスト・任意）

【セクション6：作ったものと、使ってもらった結果】
17. 個人目標に対する結果を選んでください。（選択式・1つ・必須）
 選択肢：達成／一部達成／未達／未実施
18. 何を作りましたか。名称と、組み込んだ知識・手順を最大3件書いてください。（長いテキスト・必須）
19. 誰に使ってもらいましたか。（選択式・複数回答・必須）
 選択肢：同僚・チーム／他の参加者／まだ使ってもらっていない
20. 使ってもらった相手と場面を書いてください。（長いテキスト・任意）
21. 使った人の反応を選んでください。（選択式・1つ・任意）
 選択肢：役立った／一部役立った／役立たなかった
22. 使った人の反応と、改善点を書いてください。時間短縮を示す場合は、比較の条件と確認・修正の手間も書いてください。（長いテキスト・任意）
23. うまくいかなかった点を選んでください。（選択式・複数回答・必須）
 選択肢：導入／入力準備／業務との不一致／確認の手間／なし
24. 未解決の点、続けたいこと、必要な支援を書いてください。（長いテキスト・任意）
````

## 生成後に手で設定する項目

分岐と配布の設定は、Copilot が生成しない前提で手で設定する。

### 分岐

`Add branching` で次のとおり設定する。

| 設問・位置 | 回答 | 移動先 |
|---|---|---|
| 設問6 | PM・PLの業務のみ ／ 両方 | セクション2 |
| 設問6 | 開発の業務のみ | セクション3 |
| 設問6 | どちらも担当していない | セクション4 |
| 設問8 | はい | セクション3 |
| 設問8 | いいえ | セクション4 |
| セクション3の終わり | ── | セクション4 |

兼務者は設問8を経由して両方のセクションを通過する。Forms の分岐は後ろの設問へしか移動できないので、業務のセクションを設問6より後ろに配置している。

### 設定

| 設定 | 値 |
|---|---|
| `Only people in my organization can respond` | オン |
| `Record name` | オン |
| `One response per person` | オン |
| `Start date` ・ `End date` | 各時点の回答期間 |

### 生成結果の確認

| 確認する項目 | 不一致のときの対処 |
|---|---|
| 設問文と選択肢が、プロンプトの文言と一致するか | 手で修正する |
| リッカート形式が、評価（星）など別の種類に置換されていないか | リッカート形式で作り直す |
| セクションの区切りが、【】の位置と一致するか | 手で区切る |

「最大3つ」「最大2つ」は、Forms の機能で制限せず、設問文で伝える。

## 設計書との差異

| 差異 | 理由 |
|---|---|
| 設問6と設問8を追加した | 担当業務で分岐させるため。職種の選択肢だけでは兼務を判定できない |
| 設問10（N1）の選択肢を文にした | 設計書の「使いどころ／依頼方法……」は短縮表記なので、回答者が読める文へ展開した |
| 中間の設問16を追加した | 設計書は「当初の目標・変更理由を残す」と規定しているが、それを尋ねる設問が無い |
| 人気投票を含めていない | 設計書では、最終共有会で実施する別の施策である |

Copilot のプロンプトには文字数の上限が在る可能性がある。途中で切れた場合は、事前アンケートのプロンプトをセクション3までとセクション4以降に分割し、2回に分けて貼る。
