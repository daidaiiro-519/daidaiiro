# Microsoft Forms の Copilot に渡すアンケートのプロンプト

[アンケート・効果測定案](survey-and-evaluation.md) の設問を、Microsoft Forms の Copilot へそのまま貼れる形にしたものである。フォームは、事前アンケート・参加時アンケート・参加者の終了時アンケート・参加しなかった希望者の終了時アンケートの4本である。設問の文面は `src/survey.json` から `src/build_survey_docs.py` で作っており、同じ設問は4本のどれでも同じ文面にする。**どのプロンプトも2000字以内である**（作るときに検査する）。

## 進め方

| 手順 | 作業 |
|---|---|
| 1 | フォームごとに、プロンプトを Copilot に貼り、フォームを生成する |
| 2 | 生成結果をアンケート・効果測定案と照合し、分岐と設定を手で入れる |
| 3 | 4本とも、事前と同じ文面で聞く設問の文言が一致しているかを照合する |

プロンプトの末尾に分岐を書いているが、Copilot が分岐を設定するとは限らない。生成後に、下の「生成後に手で設定する項目」の表で分岐を確認する。Copilot は生成のたびに文言を変える可能性があるので、手順3の照合を省略しない。

## 1. 事前アンケート

10月、オリエンテーションと教材の動画を公開する前に、Teamsやメールで希望者に案内する。約3分。最後の設問で、ポータルのアカウントの発行を希望した人にアカウントを発行する。（プロンプトは978字）

````
社内のAI活用ワークショップの「事前アンケート」を作成してください。準備期間の希望者が、教材の動画を見る前に回答します。クイズや点数は不要です。設問文と選択肢は、言い換えずにそのまま使ってください。【】はセクションの区切りで、1つのセクションを1画面にします。（任意）と書いた設問以外は必須、（複数選択）・（最大）と書いた設問以外は1つ選択です。リッカート・評価（星）・ランキングは使わず、選択肢の設問にしてください。

フォームの説明：ワークショップの準備と、効果を比べる元を取るためのアンケートです。7問・約3分。選択式が中心です。回答は運営だけが見ます。名前は、ほかの回の回答と突き合わせるためだけに使います。人事評価や業務評価には使いません。

【いまのAIの使い方】
1. 担当している業務を選んでください（複数選択）。
提案・見積／要件定義／設計／実装／テスト／運用・保守／PM（進捗・課題の管理）／PL（取りまとめ・技術の判断）／顧客や関係部署との調整／事務・管理／その他
2. この4週間に、仕事でAIをどのくらい使いましたか。
ほぼ毎日／週に数回／週に1回くらい／月に数回／月に1回より少ない／使っていない
3. AIが作ったものの確認や修正に、いまどのくらい手間がかかっていますか。
ほとんどかからない／少しかかる／かなりかかる／作り直した方が早いことが多い／AIを使っていない
【チームでの使い方】
4. チームで、AIの使い方（Skillsや手順、うまくいった依頼の仕方など）を共有していますか。
共有していない／一部の人だけ／共有しているが使われていない／共有していて使われている／チームでAIを使っていない
5. 新しくチームに入った人が、AIを使って仕事を始められるまで、どのくらいかかりますか。
数日以内／1〜2週間／1か月くらい／1か月より長い／新しく入った人はいない
【困りごととアカウント】
6. いま、AI活用で困っていることがあれば選んでください（最大3つ・任意）。
使う場面が分からない／依頼の仕方が分からない／結果の確認の仕方が分からない／作ったものを共有できない／使えるツール・環境が無い／時間が取れない／その他
7. 教材を見るための、ナレッジ共有ポータルのアカウントを希望しますか。
希望する／希望しない
````

## 2. 参加時アンケート（12月中）

````

【改善 2件目】

13. もう1つ、改善したいことを書きますか（最大3件）。
はい／いいえ
【改善 3件目】
14. 改善したいことを1文で書いてください（3件目）。（1行の記述・任意）
15. 誰のための改善ですか（複数選択）。
自分／チームの人／上長／顧客や関係部署／その他

19. 教材を見る前と比べて、改善したい業務の目的と、満たす要件を明確にできるようになったと感じますか。

分岐（ほかの回答は次のセクションへ）：1で「今回は見送る」→フォームの終わり／7で「いいえ」→19／13で「いいえ」→19

## 3. 参加者の終了時アンケート

ワークショップの終わりに、参加者に配る。参加時に書いた本人の改善を、案内のメールと各セクションの説明に載せる。いまのAIの使い方の設問は、事前アンケートと同じ文面である。振り返りの設問は、作ったSkillsを同じチームの人にも使ってもらった人だけに出す。（プロンプトは1426字）

````
社内のAI活用ワークショップの「参加者の終了時アンケート」を作成してください。参加者がワークショップの終わりに回答します。クイズや点数は不要です。設問文と選択肢は、言い換えずにそのまま使ってください。【】はセクションの区切りで、1つのセクションを1画面にします。（任意）と書いた設問以外は必須、（複数選択）・（最大）と書いた設問以外は1つ選択です。リッカート・評価（星）・ランキングは使わず、選択肢の設問にしてください。

フォームの説明：改善の結果と、いまのAIの使い方を伺います。改善1件なら約5分（3件で約8分）。参加時に書いた改善は、案内のメールに載せています。人事評価や業務評価には使いません。

【改善 1件目の結果】

はい／いいえ

## 4. 参加しなかった希望者の終了時アンケート

事前アンケートに回答し、ワークショップに参加しなかった人に配る。約1分。たどり着けたかの設問は、参加者の終了時アンケートと同じ文面である。（プロンプトは477字）

````
社内のAI活用ワークショップの準備期間の希望者のうち、ワークショップに参加しなかった人が回答する短いアンケートを作成してください。クイズや点数は不要です。設問文と選択肢は、言い換えずにそのまま使ってください。【】はセクションの区切りで、1つのセクションを1画面にします。（任意）と書いた設問以外は必須、（複数選択）・（最大）と書いた設問以外は1つ選択です。リッカート・評価（星）・ランキングは使わず、選択肢の設問にしてください。

フォームの説明：ポータルを使ってみた結果を伺います。3問・約1分。回答は、次の期にポータルを広げるかの判断に使います。人事評価や業務評価には使いません。

【ポータル】
1. ポータルで見つけた事例やSkillsを、自分の業務で試しましたか。
試した／見たが、試していない／ポータルを見ていない
2. ポータルで、探していた事例やノウハウにたどり着けましたか。
すぐたどり着けた／時間がかかったがたどり着けた／たどり着けなかった／探していない
3. たどり着けなかったとき、何を探していましたか（任意）（1行の記述・任意）
````

## 生成後に手で設定する項目

### 分岐

`Add branching` で次のとおり設定する。Forms の分岐は後ろの設問へしか移動できないので、全員に聞く設問を後ろに置いている。

#### 事前アンケート

分岐は無い。

#### 参加時アンケート

| 設問 | 回答 | 移動先 |
|---|---|---|
| 1 | 今回は見送る | フォームの終わり |
| 7 | はい | 8（改善 2件目） |
| 7 | いいえ | 19（明確化の実感） |
| 13 | はい | 14（改善 3件目） |
| 13 | いいえ | 19（明確化の実感） |

#### 参加者の終了時アンケート

| 設問 | 回答 | 移動先 |
|---|---|---|
| 4 | はい | 5（改善 2件目の結果） |
| 4 | いいえ | 12（いまのAIの使い方） |
| 8 | はい | 9（改善 3件目の結果） |
| 8 | いいえ | 12（いまのAIの使い方） |
| 16 | 自分だけで使った | 19（ポータル） |
| 16 | チームの人にも使ってもらった | 17（チームでの振り返り） |

### 設定

| 設定 | 値 | 理由 |
|---|---|---|
| `Only people in my organization can respond` | オン | 回答者の名前を記録するため |
| `Record name` | オン | 事前・参加時・終了時の回答を同じ人の回答として結びつけ、ポータルのアカウントの発行先を特定するため |
| `One response per person` | オン | 時点ごとに1人1回にするため |
| `Start date` ・ `End date` | 各時点の回答期間 | 事前アンケートは、動画の公開より前に終える |

### 生成結果の確認

| 確認する項目 | 不一致のときの対処 |
|---|---|
| 設問文と選択肢が、プロンプトの文言と一致するか | 手で修正する |
| 選択肢の設問が、リッカート・評価（星）・ランキングに置換されていないか | 選択肢（Choice）で作り直す |
| 「わからない」「まだ比べられない」が、尺度の最後に置かれているか | 並べ替える |
| セクションの区切りが、【】の位置と一致するか | 手で区切る |
| 冒頭の説明文が、フォームの説明に入っているか | 手で入れる |
| 終了時アンケートの各セクションの説明に、本人の改善が載っているか | 事前入力リンクか、セクションの説明で示す |
| 分岐が、上の表のとおりか | `Add branching` で設定する |
| 事前と同じ文面で聞く設問が、フォームをまたいで一致するか | 事前アンケートの文面に統一する |

「最大3つ」「最大2つ」は、Forms の機能で制限せず、設問文で伝える。
