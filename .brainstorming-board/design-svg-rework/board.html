AI が自由に記述した図の集まりで、何が同じなら統一されていると言えるか。何を作成者に任せるか

図のデザインシステムを1つにし、すべての図がそれを使う状態を「統一されている」とする。図のデザインシステムは、デザイントークン（色 ・ フォントサイズ ・ ストローク幅 ・ 角丸の半径 ・ 破線のパターン）と、スタイルごとの意味の2つを持つ。配置 ・ 図の種類 ・ 図形の組み合わせ ・ 図のサイズは、作成者に任せる

Q3

  • class の一覧（図の表記法）の図形：box ・ focus ・ warn ・ kind-1〜3 ・ boundary ・ area ・ badge ・ swatch ・ series-1〜3
  • class の一覧（図の表記法）の線とテキスト：flow ・ async ・ link ・ label ・ note
  • class ごとに意味を1つ定義する
  • デザイントークン1：セマンティックカラーは ink ・ ink-soft ・ line ・ box-fill ・ accent ・ accent-bg ・ warn ・ warn-bg と、kind-1〜3 とその背景色である
  • デザイントークン2：フォントサイズは 10 ・ 11 ・ 12 ・ 13、ストローク幅は 1 ・ 1.5 ・ 2、角丸の半径は 3 ・ 5 ・ 8、破線のパターンは 4 3 の1つである

案採らなかった理由
既存の SVG もすべて変換する承認済みの ACDR は対象の sha256 で封印されており、生成し直すには --force が必要になる。承認時点の姿が失われる
呼び出し元を先に移行するdesign-svg に class の解決が無いうちに class だけの SVG を作成すると、値が無いので fill が黒になる
canvas を残す31件の宣言で使用は0件である。作成者が SVG を直接記述する方法と、同じ目的の手段が2つになる
figure と chart を削除する論点2で、辺の多い関係図と量のグラフのために任意の手段として残すと決めた
figure と chart の出力をいまのまま（独自の class）にする検査1（class の一覧）を通らず、同じ design-svg から2種類の出力が出る
brainstorming-board の figures を残す重なりとはみ出しの検査が2か所に在り、ギャラリーでは figures だけが10件の誤検出を出した。同じものを2か所に置かない
slide-deck の8色をすべて対応させるfaint と on-accent に対応するトークンを使う class が無く、使われない対応が残る
スライドにもダークモードの style を出力するスライドのテーマが配色を決めているのに、閲覧者の OS がダークモードだと SVG だけが切り替わる
