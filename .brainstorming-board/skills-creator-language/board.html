論点の一覧

skills-creator は、利用者が自分で Skill を作るための Skill である。いまの道具の契約は Rust でしか道具を作れない形になっており、抽象の高さが合っていない。このブレストボードは、契約を言語に依存しない形にするために、契約と言語の組の境界 ・ 言語の条件 ・ 検査の形 ・ 外部の道具の宣言の置き場所を決める。このリポジトリの Skill は、引き続き Rust で作り、Rust のバイナリで配布する。
