Q1

このSkillは、原稿からどこまでを受け持つか

この答えが、残る4件の問いの形を決定する。範囲が動画の組み立てまで及ぶと、実行の場所も入出力も別の問いになる。
A

このSkillの責務は、音声の生成と再現性に限定する。

  1. 入力は、枚ごとに区切られた原稿である
  2. 出力は、枚ごとの音声ファイルと、尺の記録（各文と各語の開始時刻）である
  3. 動画への結合、スライドの画像化、再生の制御は受け持たない
この答えの完成イメージ ── 図と、実例

実例 ── 原稿1枚を音声にし、同じ原稿から尺を取る。どちらも Polly の同じ操作で得られる。

aws polly synthesize-speech \
  --text-type ssml --text "<speak>下期AI活用ワークショップの企画をご説明します。</speak>" \
  --voice-id Takumi --engine neural --output-format mp3 slide-01.mp3

aws polly synthesize-speech \
  --output-format json \
  --speech-mark-types='["word", "sentence"]' \
  --text-type ssml --text "<speak>…</speak>" \
  --voice-id Takumi --engine neural slide-01.marks.json

尺の記録が在ると、結合する側は枚の表示時間を自分で測る必要がない。音声側が知っている事実を、そのまま渡す形である。
