論点の一覧

SKILL.md 以外の中身（references。knowledge もここへ統合する）は、JSON Schema と、それに従う JSON を正本にする。人が見るときは、JSON から導出した HTML で確認する。構造があらかじめ分離されていれば、読み手は構造を解釈せずに内容に集中できる ── 人にとっても AI にとっても同じである。この方針を、道具を持つ Skill と、アドバイザー系 ・ skill-router ・ memory-cultivator を含む16の Skill へ適用する形を決める。
