Q1

Q2

Q3

判断基準の1件を、5つの原典のどの単位にするか

原典が名前を付けた単位を1件にし、合わせて67件にする。18F は方法1つ（34件）、Nielsen はヒューリスティクス1つ（10件）、WCAG 2.2 はガイドライン1つ（13件）、GOV.UK は文言の頁1つ（5件）、Design Tokens は仕様の概念1つ（5件）である。答えは、デザイナーが案を生み出す流れの順に組み、完成イメージはワイヤーフレームとデザインシステムで渡す
  • 18F Methods ── 方法1つを1件にする。発見 ・ 決める ・ 作る ・ 確かめるの段を札にする。チームの合意や会議の進め方の5件は除き、34件にする
  • Nielsen ── ヒューリスティクス1つを1件にする（10件）
  • WCAG 2.2 ── ガイドライン1つを1件にし、達成基準を要素にする（13件）
  • GOV.UK ── 文言の規則を中心に書いた頁1つを1件にする（5件）。Writing for user interfaces ・ Error message ・ Error summary ・ Validation ・ Question pages である
  • Design Tokens ── 仕様の概念1つを1件にする。Token ・ Group ・ Alias ・ Type ・ Composite token の5件で、型（Color ・ Dimension ・ Shadow ・ Typography など13種）は要素にする
  • ゴールと手順を決める ── Personas ・ User scenarios ・ Task flow analysis
  • 慣習と既存の型を調べる ── Comparative analysis ・ Design pattern library ・ Consistency and Standards
  • 案を広げる ── Design studio（一人ずつスケッチし、講評し、組み合わせる）
  • 原則で1つに絞る ── Design principles（その案件だけの原則を書き、選ぶ基準にする）
  • 完成イメージにする ── Wireframing ・ Prototyping と、デザインシステム。文言は GOV.UK、点検はヒューリスティクスと WCAG
  • 利用者で確かめる ── Usability testing ほか確かめる段の方法
