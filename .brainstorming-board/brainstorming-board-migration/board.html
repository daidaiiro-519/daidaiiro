ボードを開くと、いま答える論点が最初から開いている。論点の中は見る順に1列で並べ、閉じておくのは答えの詳しい決まりと裏づけだけにする。
  • 現在地は1行のチップ（決着 ・ いま答える ・ まだ）と「この回で答える論点：n件」にし、論点ごとのタブは並べない
  • 意味のまとまり（問いと答え ・ 完成イメージ ・ 置いた前提 ・ 確かめてほしい箇所 ・ 裏づけ ・ 回答）は、それぞれ同じ形の白い枠に入れ、見出しを枠の中に置く。枠はページの背景の上に直に並べ、面を重ねない。この回で変わったところは1行の知らせの帯にする
  • 問いと答えは1つの枠にまとめ、「問い」と「答え（承認してほしいこと）」のラベルを付ける。答えは枠の中の色付きの面に置く
  • 答えは1文だけを見せ、下位の決定は「答えの詳しい決まり（n件）」を開いて読む
  • この回で変わったところは、件数と行き先を1行で出す。押すとその文へ移って光り、変わった文の中に前の回の文と変えた理由が出る
  • 置いた前提は、完成イメージのすぐ後に番号付きで並べる
  • 確かめてほしい箇所は3件までにし、「移る先 ── 何を確かめてほしいか」の1行で書く。押すとその箇所へ移って光る
  • 裏づけは主張ごとに束ね、各主張の根拠は2件まで見せ、残りは「ほかの根拠 n件」で開く。見出しに主張 ・ 根拠 ・ 採らなかった案の数を出す
  • 採らなかった案は、表にせず「案 ── 採らなかった理由」の1行にする
  • 知らないかもしれない語は、ページで最初に出るところにだけ ⓘ を付ける。押すと説明が出て、Esc で閉じる
  • 回答は「このまま進める」「差し戻す」の2つにする。差し戻すを選ぶと「どこが違うか」の欄が出て、空のままでは送れない。書き足しは任意である
  • 送ったら、次にすること（チャットで一言もらう）を画面が言い切る
  • 完成イメージのタブ名は図 ・ 画面 ・ コードにし、題の上は「第n回」にする

Q3

ボードの見た目（トークン ・ 部品 ・ 状態）をどう決め、基盤のカタログとどう関係させるか

ブレストボード ・ ACDR ・ アドバイザーの回答の頁 ・ 基盤の文書を1つのデザインシステムにそろえ、基盤のカタログが持つ。値は論点2の試作の見た目をそのまま決まりにし、Skill が上書きしてよいトークンは無しにする。
  • 3つの頁は、どれも AI が作ったものを人が短く確かめて、承認するか直すかを決める頁である。違いはページテンプレートの並べ方と中身で出し、色 ・ 面 ・ 部品の形では出さない
  • トークンは base の色と、ライト ・ ダークの意味の層の2層にする。意味の層は base を参照し、19の名前（面5 ・ 文字6 ・ 主役1 ・ 線4 ・ 状態3）を持つ
  • 面は、ページ（グレー）と、まとまり（白）と、まとまりの中の内側（図やコードを置く面、#edf2ef の少し濃い色）と、答え ・ 知らせの色付きの面にする。内側は面の色で白い枠と区別し、線を足さない。グレーの面の上に中くらいのグレーの文字を置かない
  • 文字は、本文 ・ 補足 ・ 主役 ・ 主役の上 ・ 注意 ・ 原典の6つにする。文字は 4.5:1 以上、部品の境界は 3:1 以上にする
  • 線は、操作できる部品 ・ まとまり ・ 区切り ・ 知らせの4つに分ける
  • 書体はいまのボードの3つ（本文 Zen Kaku Gothic New ・ 見出し Shippori Mincho ・ 番号 JetBrains Mono）にし、寸法は rem で持つ
  • 状態は、通常 ・ ホバー ・ 押した ・ 焦点 ・ 無効 ・ 光る（移った先）の6つにする。焦点は主役の色の外枠、光るは注意の色の外枠にする
  • カタログには、現在地 ・ 問いと答え ・ 語のヘルプ ・ 主張ごとの束の4つの部品を足し、document ・ mark ・ tabs ・ jump ・ choose ・ write ・ send など9つを変える
  • 図の色も、このデザインシステムのトークンから引く。図の決まり（design-svg）の主役の色 ・ 答えの面 ・ 暖色の面 ・ 注記の色を、ページと同じ意味のトークンに結びつけ、暖色は1つの系統（砂色）にそろえる。図の注記の字の大きさも見直す
  • 主役の色は青緑 #0d5c55 にする。苔緑 #4a6741 も、完成イメージで切り替えて見比べられる。どちらもコントラストの下限を満たす
  • 順番を持つ並び（置いた前提 ・ 確かめてほしい箇所 ・ 答えの詳しい決まり ・ 見る順）は、主役の色の丸に白い番号を入れて並べる。確かめてほしい箇所は、1件ごとに「どこを見るか（押すと移る）」と「何を確かめるか」を2段に分ける
  • 裏づけは、主張を主役の色の左線の見出しにし、根拠と採らなかった案を1件ずつのカード（内側の面の色と線）にする。根拠のカードは、上の段に種類のバッジと出どころ、下の段に本文を置く
  • これと食い違う2つの決定を改訂する。ボード acdr-redesign で決めた「ACDR が自前のデザインシステムを持つ」と、アドバイザーの回答の頁が Skill ごとにパレットを選ぶ形である。acdr-redesign の色の決定（苔緑）は、主役の色の案として残す
