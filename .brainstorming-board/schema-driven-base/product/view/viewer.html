課題
課題

このプロダクトがなぜ必要か。誰が何に困っているか。

AI が扱うデータを Markdown の文書で持つと、欄の場所が決まらず、AI は文字列を探して読むことになる。指す先が消えたことや、答えと宣言した値の食い違いに、書いた時点で気づけない。同じ読み書きの能力を道具ごとに書くので、道具どうしでずれる

人が読む頁を正本から描画する頁の型と部品で、実体の集合から人が読む頁を組む―描画 補完
基盤の能力を複製して配れる基盤を使う道具へ正本の複製を転写し、正本との差を道具が出す―転写 補完

競合

競合欠けている提供価値
Markdown の文書を正本にするやり方「欄を式で指して読み書きできる」「参照と判定のずれを道具が出す」が無い
JSON Schema の検証器だけを使うやり方「参照と判定のずれを道具が出す」「人が読む頁を正本から描画する」が無い
