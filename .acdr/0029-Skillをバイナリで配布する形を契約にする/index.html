承認承認を得た。適用してよい2026-09-28

skills-creator の道具の契約に従うすべての Skill を、利用者の環境に Rust が無くても動く実行ファイルとして配布し、その形を skills-creator の契約 ・ テンプレート ・ 検査に実装する。

なぜ、いま決めるのか

いまの配布物（skills.zip ・ qa-advisor.zip）は、ソースをまとめた zip で、実行ファイルを1つも含まない。受け取った人は Rust で組み立てる必要があり、各 Skill の mcp.json は開発機の絶対パスを指している。利用者の要件は、組み立て済みの実行ファイルを渡し、Windows ・ WSL ・ macOS で、どのバイナリかを意識せずに使えることである。配布の形は、このリポジトリの道具を持つ9つの Skill に限らず、契約に従うすべての Skill に共通する。ブレストボード（.brainstorming-board/skill-binaries/）で検討し、2026-09-28 に5つの論点とも決定した。

形の変化

何がいまの形これからの形
利用者の操作（論点1）zip を展開し、Rust で組み立て、mcp.json の経路を書き換えるシェルに合った1行を実行する。導入スクリプトが OS と CPU を判別し、合う配布用の zip を取得して展開する

案採らなかった理由
環境ごとの zip を利用者が選ぶ利用者が自分の環境を知り、正しい zip を選ぶ必要がある。利用者の指定（どのバイナリかを意識しない）に違反する
Claude Code のプラグインとして配布するプラグインの Skill は /プラグイン名:skill名 という名前になり、配線表と CLAUDE.md の Skill 名をすべて書き換えることになる
rs/ の名前を維持する、または src/ にするrs/ は言語の名前で、中身の役割を示さない。src/ は中の crate の src/ と2回続く
Windows ネイティブを当面未対応にし、WSL を案内する利用者が指定した対象の環境から Windows を外すことになる
既存の date ・ timeout の4か所だけを置き換える次に生成する Skill がまた date を呼んでも、検出されない
