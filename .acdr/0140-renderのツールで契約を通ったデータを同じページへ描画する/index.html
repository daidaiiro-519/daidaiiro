render のツールで、契約を通ったデータを同じページへ描画する

決めたこと

基盤のツール render は、検証を通ったインスタンスだけを、同じ入力から同じページへ描画する。何も指定が無いときは基盤の文書の契約と決まったデザインで、具体がスキーマとデザインテンプレートを持つときは具体のもので描画する

なぜ決める必要があるか

描画の能力は基盤が持ち、具体の表現は具体が持つ（ACDR 0132 ・ 0136）。利用者と、render に渡すのはデザイン ・ ページテンプレート ・ 契約を通ったインスタンスで、同じ入力なら出力も同じでなければならないと確かめた。さらに、artifact-design のように何も指定が無いときも描画できる UX を求められた（ボードの論点7）。スキーマの形から表現を推し量る既定のページは、宣言の実物で読めなかったので、書く側が情報の種類でブロックを選ぶ文書の契約にした。宣言の UC-6 は 0132 より前に書いたままなので、宣言のファイルを移すまでは、この ACDR を UC-6 の改訂とする。

どう変わるか

変更前と変更後

何が変更前変更後
何も指定が無いとき宣言の UC-6：ページテンプレートが無い種類は、注釈だけから描画する基盤の文書の契約（references/document.schema.json、14種類のブロック）に合うインスタンスを、決まったデザイン（references/document-design）で描画する
具体のスキーマの種類──具体のページテンプレートとデザイン（Toolbox に渡す Renders）で描画する。テンプレートもデザインも無い種類があれば、何も書かずに「デザインテンプレートが無い種類がある」で失敗する
描画するデータ決めていない検証を通ったインスタンスだけ。検証エラーが1件でもあれば何も書かずに失敗する。未記入は止めない（ACDR 0118）
再現性と冪等性宣言の REQ-1 の未決の事項全ページを生成してから書く。内容が変わったページだけを書く。入力を書き換えない。テストで、2回目の出力が1バイトも変わらないことを確かめる
安全──文の中のリンクは http(s) と文書の中の場所だけ。埋め込む SVG は script ・ イベントの属性 ・ javascript: を含むなら断る

比較した案と、採らなかった理由

案採らなかった理由
スキーマの形から表現を推し量る既定のページ値の形からは情報の種類が決まらない。宣言の実物で描画すると、手順や拡張が表と一覧の入れ子になって読めなかった
テンプレートの無い種類は描画せず、一覧で返す基盤だけでは何も描画できない。基盤は単独でも使えると決めている（基盤のボードの論点4）
検証エラーのあるインスタンスも描画し、ページに印を付ける契約を通っていないデータを、正しいものとして見せてしまう
文の中に HTML を書けるようにするエスケープの漏れと、危ない属性の混入を、書く側ごとに防ぐことになる。強調 ・ コード ・ リンクの3つだけを決まった書き方で受ける

59/// 文の中の書き方（**強調**、`コード`、[文字](URL)）を部品にする。それ以外の文字は、すべてエスケープする。
60fn inline(renderer: &dyn Renderer, text: &str) -> Result<Html, String> {
61 let mut html = Html::default();
62 let mut plain = String::new();
63 let mut rest = text;
64 while !rest.is_empty() {
65 if let Some(after) = rest.strip_prefix("**") {
66 if let Some(end) = after.find("**") {
67 html.push(renderer.text(&std::mem::take(&mut plain)));
68 html.push(renderer.part("strong", &[("text", renderer.text(&after[..end]))])?);
69 rest = &after[end + 2..];
70 continue;
71 }
72 }
73 if let Some(after) = rest.strip_prefix('`') {
74 if let Some(end) = after.find('`') {
75 html.push(renderer.text(&std::mem::take(&mut plain)));
76 html.push(renderer.part("code-inline", &[("text", renderer.text(&after[..end]))])?);
77 rest = &after[end + 1..];
78 continue;
79 }
80 }
81 if let Some(after) = rest.strip_prefix('[') {
82 if let Some(label_end) = after.find("](") {
83 if let Some(url_end) = after[label_end + 2..].find(')') {
84 let label = &after[..label_end];
85 let url = &after[label_end + 2..label_end + 2 + url_end];
86 if !allowed_url(url) {
87 return Err(format!(
88 "リンクの URL は http(s) か文書の中の場所（#…）だけ書ける：{url}"
89 ));
90 }
91 html.push(renderer.text(&std::mem::take(&mut plain)));
92 html.push(renderer.part(
93 "link",
94 &[("href", renderer.text(url)), ("text", renderer.text(label))],
95 )?);
96 rest = &after[label_end + 2 + url_end + 1..];
97 continue;
98 }
99 }
100 }
101 let character = rest.chars().next().unwrap_or_default();
102 plain.push(character);
103 rest = &rest[character.len_utf8()..];
104 }
105 html.push(renderer.text(&plain));
106 Ok(html)
107}

408 "section",
409 &[

417 )?);

438 ("url", url),
439 ],
