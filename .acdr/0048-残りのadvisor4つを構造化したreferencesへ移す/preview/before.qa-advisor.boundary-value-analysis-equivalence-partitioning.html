節

境界値分析と同値分割によるテスト設計技法を対象とする概念：boundary-value-analysis-equivalence-partitioning

概要

この概念が答える判断
  • 無限にありうる入力値の組み合わせを、どう絞り込んでテストすればよいか？
  • 同じ入力パーティションの中で、どの値を優先してテストすべきか？

入力値空間を「同じ処理をされるはず」という前提でグループ分けし(同値分割)、その中でも特にエラーが起きやすい境界(エッジ)を狙って検証する(境界値分析)、古典的なテスト設計技法。

原則

  • 同値分割は、あるパーティション内の全要素が同じ方法で処理されるという期待に基づいてデータを分割する技法であり、『あるパーティション内の1値で欠陥が検出されれば、同パーティション内の他の値でも同じ欠陥が検出されるはず』という前提に立つ。
  • これにより、無限に近い入力の組み合わせを、代表値をテストするだけで済む程度まで絞り込める。
  • 境界値分析は、パーティションの中間値ではなく境界(エッジ)を狙って検証する技法である——開発者は境界値(例: 範囲の最小値・最大値・その1つ外側)でエラーを起こしやすいという経験則に基づく。

分類

分類特徴
同値分割入力空間を『同じ処理をされるはず』という前提でグループ分けし、各グループから代表値を1つ選んでテストする
境界値分析各パーティションの境界(最小値・最大値・その前後)を狙って検証する

判断基準

同値分割と境界値分析は排他的な選択肢ではなく組み合わせて使う技法であり、機械的な分岐判断は存在しない。

実例

「1〜100の整数を受け付ける」という仕様があるとき、同値分割では『1〜100(有効)』『0以下(無効)』『101以上(無効)』の3パーティションに分け、各パーティションから代表値(例: 50, -1, 101)を選ぶ。境界値分析ではさらに踏み込み、各パーティションの境界である0, 1, 100, 101を重点的に検証する。

アンチパターン

アンチパターン問題点
パーティション内の中間値だけをテストする境界値でのオフバイワンエラー(範囲の端が1つずれる不具合)を見逃しやすい

出典・根拠の透明性

Glenford J. Myers『The Art of Software Testing』に起源を持つ同値分割・境界値分析の概念が、ISTQB(International Software Testing Qualifications Board) Foundation Level Syllabusで標準的なブラックボックステスト技法として整理されている。
