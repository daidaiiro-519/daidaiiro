# 追加した比較図の原則の確認

比較対象の見出し・状態・結果がどちらに属するかを明確にし、共通部分の表現を対応させ、違いとその結果を直接読み取れるようにする。

| 設計すること | 描画後に確かめること |
|---|---|
| 比較対象ごとに意味のまとまりを作る | 見出し・状態・根拠・結果が、どの対象に属するか分かるか。別の対象と混同する場合は、枠や領域を分ける。 |
| 対応する内容を同じ位置と形で置く | 共通部分の配置を解読せず、同じ項目の違いを比べられるか。 |
| 伝えたい違いだけを強調する | 強調した箇所が、比較で伝えたい違いと一致するか。共通部分まで強調していないか。 |
| 条件の違いを具体的な結果へつなげる | 必要な場合、同じ操作・入力に対する結果を示し、違いの影響を読み取れるか。 |

図の見方の説明を外して画像だけを見たとき、比較対象、対応する項目、違い、その影響が読み取れるかを確認する。ナレーションは内容を説明し、対象の所属や配置を解読するための説明にしない。

左右のカードや対象ごとの枠を必須にしない。共通の時間軸や位置そのものに意味がある場合は、その対応を保つ。枠と共通部分の複製で情報量が増えるなら、比較する項目を減らすか別の形を選ぶ。

適用例は document.json の comparison-boundaries-example、実際の変更前後の図は references/examples/comparison-boundaries/README.md にある。この判断基準は、AIワークショップの図への利用者の指摘と評価をもとに追加した実務上の原則であり、外部の研究で検証した規則ではない。
