ACDR の印だけを数える

決めたこと

変更の件数と、印の検査（data-b と data-w の数）を、ACDR が付けた印（data-acdr）だけで数える。

なぜ決める必要があるか

ACDR 0110 で、ACDR が付けた印に data-acdr を足し、画面の動きはその印だけを扱うようにした。数える側は class="chg" のままだったので、ボードを描画した面を置いた ACDR 0111 で、ボード自身の印まで数えて「変更 202 件」と出た（正しくは10件）。印の検査も、ボード自身の印を数えて不合格になった。

どう変わるか

変更前と変更後

何が変更前変更後
変更の件数class="chg" の印をすべて数えるdata-acdr の付いた印だけを数える
印の検査class="chg" の印の data-b と data-w を数えるdata-acdr の付いた印だけで数える

比較した案と、採らなかった理由

案採らなかった理由
ボードの側で、印の class を変える対象の文書は ACDR を知らない。ACDR の側が自分の印を見分ければ、どの文書でも同じに動く（ACDR 0110 と同じ判断）
件数の表示を外す件数は、理由の欠けを見つける検査にも使っている
