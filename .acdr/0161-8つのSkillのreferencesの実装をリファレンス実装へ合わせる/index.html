意思決定の記録 ・ ACDR 0161 ・ 2026-10-08 ・ 承認

8つの Skill の references の実装を、リファレンス実装へ合わせる

決めたこと

advisor 以外の8つの Skill の references の実装 refs.rs を、skills-creator のリファレンス実装 refs.rs.tmpl から複製し直す。対象は acdr ・ design-svg ・ doc-writing-skills ・ fact-check ・ session-memory ・ skill-router ・ slide-deck ・ slide-deck-speech

なぜ決める必要があるか

2026-10-06 の ACDR 0115 ・ 0119 ・ 0127 の承認で、refs.rs.tmpl に図の並び（figures）の描画が入った。advisor 6つには複製したが、ほかの8つには複製していなかった。そのため skills-creator check --cases 1 が、8つの Skill で2件ずつを検出していた。1件は refs.rs がリファレンス実装と違うこと、もう1件はケース a_figure_unit_draws_its_related_figures_in_order の出力が期待値と違うことである。ACDR 0160 の作業で見つかった。

変更前と変更後

何が変更前変更後
8つの Skill の refs.rsrefs.rs.tmpl の 2026-10-06 より前の形（図の並びを描かない）refs.rs.tmpl と同じ。図の並び（figures）を1枚ずつ欄で描く
skills-creator check --cases 115の Skill のうち8つが2件ずつ（計16件）15の Skill すべてで 0件
8つの Skill のテストと実行ファイル—cargo test がすべて合格した。acdr 90件 ・ design-svg 214件 ・ doc-writing-skills 46件 ・ fact-check 28件である。session-memory 3件 ・ skill-router 3件 ・ slide-deck 60件 ・ slide-deck-speech 8件である。clippy は 0件で、tool.json の build で bin/ を作り直した

比較した案と、採らなかった理由

案採らなかった理由
図の並びの処理だけを、各 Skill の refs.rs へ手で足すskills-creator は refs.rs をリファレンス実装の複製として扱い、一致しなければ複製し直すと決めている（document.json の契約）。手で足すと、次の変更で再び差が出る
図の並びを使わない Skill は、古い refs.rs のままにするcheck が差を検出し続け、ほかの差が混ざっても気づけない。使わない処理を持っても、描画の結果は変わらない

ここから下は、この決定で変わるファイルごとの差分である。タブでファイルを切り替える。
