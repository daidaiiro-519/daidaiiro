# 意思決定の記録

ACDR は Any Change Decision Record である。決めたことを、変更前と変更後の差分ごと1枚に保存する。組むのは `.claude/skills/acdr/` である。

| 番号 | 題 | 状態 | 日付 |
|---|---|---|---|
| [0001](0001-acdr-を新設し-change-record-を統合する/index.html) | ACDR を新設し、change-record を統合する | **承認** | 2026-09-21 |

状態は3つだけである ── **提案**（まだ適用してはならない）／ **承認**（適用してよい）／ **差し替え済み**（後の記録が置き換えた）。

置き換えられた記録は消さない。状態を差し替え済みにして、置き換えた記録を指す。
