道具を持つ9つの Skill を、ACDR 0032 で改訂した道具の契約に従う形（tool/ ・ bin/ ・ Skill のフォルダの求め方 ・ 外部の道具の宣言）へ移す。

なぜ、いま決めるのか

ACDR 0032 で skills-creator の道具の契約を改訂した。道具を持つ9つの Skill は、改訂した check で同じ4件の不合格になっていた。道具のソースが rs/ にある ・ tool/ が無い ・ .gitignore に bin/ が無い ・ 登録に絶対パスがある、の4件である。移さなければ、配布物を組み立てられない。

形の変化

何がいまの形これからの形
道具のソース9つとも rs/9つとも tool/（git mv による改名。中身は下の変更を除いて同じ）
実行ファイルrs/target/release/。開発機だけに在るbin/。cargo install --root . で置き、git で追跡しない
Skill のフォルダの求め方acdr と doc-writing-skills は build 時の絶対パス、他の5つは実行した場所（"."）9つとも Given::skill_root（--skill_root が無ければ実行ファイルの1つ上）。見つからなければ誤用として返す
外部コマンドdate（acdr ・ brainstorming-board ・ fact-check）と timeout（narration）を呼ぶRust の中で行う（chrono の地域の時刻 ・ 子プロセスを待つ処理）。呼んでよい道具は REQUIRES に宣言する（git ・ curl ・ aws ・ 利用者が指定する道具）
経路の記述SKILL.md ・ rules.json ・ .mcp.json ・ CLAUDE.md など20ファイルの145行が、rs/ の経路を書いていたbin/ と tool/ へ機械的に置き換えた

比較した案

どれも反証を通過しなかった案である ── 未解決のまま残っているものではない。

案採らなかった理由
date を協定世界時で作る（chrono を加えない）日本時間の午前9時より前に作った記録の日付が前日になる。date は利用者の地域の時刻を返していた

自身の役割

Orchestratorである。作業を受け取ったら、skill-router に配線表を引かせ、返ってきたSkillを呼び、結果を突き合わせて1つの答えにする。

skill-router配線表の読み方

配線表は「いつ呼ぶか」を保持しない。作業の前に材料を集めるのか、作業のあとに十分かを確認するのか、両方かは、そのつどOrchestratorが決める。

対象タイミングアクション理由
skill-router作業の前作業の名前と対象を渡し、配線表に行があるかを確認する。行があれば request と skills を、続く委譲への入力にする。配線表が見つからないことは失敗として扱わず、配線が1件も無いものとして進む呼ぶ相手を決める窓口を1か所に置くため
助言専門のSkill（ddd-advisor ・ tech-lead-advisor ・ platform-advisor ・ qa-advisor ・ ux-advisor）作業の前、作業のあと、または両方skill-router が返したSkillごとに、目的・役割・読み込むSkill・タスク・成果物・受け入れ基準を組み立て、1回のメッセージで並列に呼ぶ。全員の結果を受領したら、各回答が指定したテンプレートの見出し構造を実際に踏襲しているかを確認してから統合する。踏まえていない回答は、内容の質も未検証とみなして呼び直す要約した指示を渡す代行では、受け手がテンプレートの読み込みまで遂行する保証が無いため
作る側のSkill（acdr ・ brainstorming-board ・ design-svg ・ doc-writing-skills ・ fact-check ・ skills-creator ・ advisor-creator）作業の途中skill-router が返した request をそのまま渡す。Skillの内部形式に合わせて整形せず、テキストのまま渡すSkill同士が互いの内部形式を事前に知らなくてよくするため
memory-cultivator作業のあと次のセッションが続きから始めるために必要な事実（進行中の作業の現在地、次にすること、外部システムへのポインタ）が生じたとき、またはユーザーから覚えておくよう頼まれたときに呼ぶ。恒久の決まり（次から遵守させる規則）は渡さない ── それは、それが適用されるSkillのガードレールが持つ記憶は一時的なものだけを置く場所である。恒久の決まりをここへ複製すると、遵守させたい場所に無いまま増える
