提供者の検証を、シェルのスクリプトから契約の道具へ移す

意思決定の記録 ・ ACDR 0077 ・ 2026-10-01 ・ 承認

提供者の検証を、シェルのスクリプトから契約の道具へ移す

決めたこと

提供者が雛形を直したときの検証（5言語 × 2型の生成と突き合わせ）を、シェルのスクリプトではなく、skills-creator の道具の契約に従う提供者の道具で行う。

なぜ決める必要があるか

tool/verify-profiles.sh（ACDR 0070）は、skills-creator の能力でありながら道具の契約の外にあった。bash ・ tar ・ sed ・ eval で組み立てのコマンドを解釈し、検出は人が読む文字列だけで返した。bash の無い環境（Windows など）では実行できず、ほかの Skill が遵守する「Linux に依存しない」という決まりにも反していた。利用者に「なんで sh なの？」と問われ、是正を指示された（「契約の外で作成されたものの是正もやるにきまってるでしょ」）。突き合わせ（conform）も、cargo の example の独自の入口で、契約の規約（旗の検査 ・ --json）を持たなかった。

どう変わるか

変更前と変更後

何が変更前変更後
検証の実装bash のスクリプト（tar ・ sed ・ eval ・ python3 で JSON を読む）Rust の業務ロジック（business_logic/src/provider.rs）。組み立てのコマンドを語の並びとして起動し、検出を JSON で受け取る
入口tool/verify-profiles.sh と、突き合わせだけの cargo の example（conform）提供者の道具の一覧（verify ・ conform）と、cli の example（provider）。規約は利用者の CLI と同じ
利用者への見え方（配布物に入らない）変化しない。利用者の道具の一覧と MCP には出さない
作業場所既定は一時フォルダ。同じ名前を消して作り直す（rm -rf）既定は tool/target/verify。その下に run-<番号> を新しく作り、既存のものを削除しない

比較した案と、採らなかった理由

案採らなかった理由
スクリプトを残し、PowerShell 版も用意する同じ検証を2つの言語で書くことになり、片方だけが古くなる。検出を JSON で受け取れない点も残る
verify を利用者の道具の一覧に加える利用者に使う場面が無く、MCP の一覧にも出てしまう。ACDR 0070 が突き合わせを配布物から外した理由と同じである
提供者の入口のために、CLI の旗の読み方を複製する旗の検査と終了コードの規約を2回書くことになり、片方だけが古くなる。sc_cli の関数に1つだけ置く

下に並ぶのは、この決定を採ったときに何がどう変わるかである ── 上の決定の具体である。

10/// 旗と位置引数を読み、渡された引数を組む。
11///
12/// **旗は `--名前=値` と `--名前 値` の両方を受ける** ── 書き方を1つに強制すると、
13/// 既存の手順が壊れる。**値を伴わない旗は、立っている** ── 空欄とすると、`--check` が
14/// 黙って逆の意味になる。**次が別の旗なら、それは値ではない。**
15///
16/// **まとめて受ける引数は、繰り返すと足りていく。** 上書きにすると、2つ目以降を黙って
17/// 破棄することになる（実測で `--layer` が1件しか残らなかった）。
18fn read_args(tool: &Tool, rest: &[String]) -> Result<Given, String> {
19 let mut given = Given::default();
20 let mut positional: Vec<String> = Vec::new();
21 let mut i = 0;
22 while i < rest.len() {
23 let a = &rest[i];
24 if let Some(body) = a.strip_prefix("--") {
25 let (key, value) = match body.split_once('=') {
26 Some((k, v)) => (k.to_owned(), v.to_owned()),
27 None => match rest.get(i + 1) {
28 Some(v) if !v.starts_with("--") => {
29 i += 1;
30 (body.to_owned(), v.clone())
31 }
32 _ => (body.to_owned(), "1".to_owned()),
33 },
34 };
35 let key = key.replace('-', "_");
36 // **道具の一覧に無い旗は断る。** 黙って無視すると、打ち間違いが検出されない
37 if !tool.args.iter().any(|a| a.name == key) {
38 let known: Vec<&str> = tool.args.iter().map(|a| a.name).collect();
39 return Err(format!(
40 "その旗は無い: --{key}（{} は {} を受ける）",
41 tool.name,
42 known.join(" ・ ")
43 ));
44 }
45 given.push(&key, value);
46 } else {
47 positional.push(a.clone());
48 }
49 i += 1;
50 }
51 // **位置と旗を混ぜて渡せる。** 旗で渡したぶんを数えずに位置だけで判定すると、
52 // 旗を使った呼び方が「引数が足りない」になる
53 let mut free = positional.into_iter().peekable();
54 for arg in &tool.args {
55 if given.has(arg.name) {
56 continue;
57 }
58 if arg.many {
59 // **まとめて受ける引数は、残りの位置引数を全部取る**
60 for v in free.by_ref() {
61 given.push(arg.name, v);
62 }
63 continue;
64 }
65 if let Some(v) = free.next() {
66 given.push(arg.name, v);
67 } else if let Some(d) = arg.default {
68 given.push(arg.name, d.to_owned());
69 }
70 }
71 Ok(given)
72}
