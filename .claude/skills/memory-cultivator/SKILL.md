# memory-cultivator

## 目的

進行中の作業の現在地や、外部システムへのポインタなど、**次のセッションが続きから始められるようにするためだけ**の一時的な事実を記録するときに使う。記録するのは project と reference の2種だけで、**守ってほしいこと（恒久の決まり）は記録しない** ── それは、それが効く Skill のガードレールか knowledge が持つ。

**記憶は一時的なものだけを置く。**置いてよいのは、次のセッションが続きから始めるために要る現在地と、
外を指すポインタである。**作業が終わった項目は消す。**

| 置くか | 何が当たるか | 置かないなら、どこへ |
|---|---|---|
| **置く** | 進行中の作業の現在地、次にすること、未決のまま持ち越すこと | ── |
| **置く** | 外部システム・URL・チケットへのポインタ | ── |
| **置かない** | 次から守ってほしいこと、是正されたやり方 | **それが効く Skill のガードレール** |
| **置かない** | 判断の材料になる概念・原則 | **knowledge** |
| **置かない** | 利用者自身の役割・知識・好み | **それを使う Skill**（そこでしか効かない） |

**「How to apply」を書きたくなったら、それは記憶ではない。**
次から守ってほしいことなので、守らせたい場所へ置く。

---

## 役割

- 進行中の作業の現在地と、外を指すポインタを検知し、project / reference のどちらかに分類する
- 分類した内容を、対応するテンプレートに沿って共有される記憶ストアへ記録する
- 記憶ストアの索引を更新する
- 明示的な記録依頼があれば、検知トリガーを問わず即座に記録する

---

## 処理対象と成果物

### 処理対象

進行中の作業の現在地・次にすること・外を指すポインタ、または明示的な記録依頼

### 成果物

共有される記憶ストアへの記録ファイル（frontmatter付きMarkdown）と、更新された索引

---

## 入力の想定

| 受け取る情報 | 解釈・既定値 |
|---|---|
| 検知トリガーの種別（自動検知された出来事か、明示的な依頼か） | 明示されなければ、直前の会話に「訂正」「決定」「覚えておいて」に相当する内容が含まれるかで判定する |
| 記録する型（project / reference のいずれか） | 明示されなければ内容から推測する。project=進行中の作業の現在地、reference=外部システムへのポインタ。**どちらでもないなら記録しない** |

---

## 実行手順

### Step 1: 記録すべき出来事かを判定する

直前の会話に、**次のセッションが続きから始めるために要る事実**が現れたかを判定する。恒久の決まり・概念・利用者自身の性質は対象外で、行き先は上の表が決める。個人の伝え方・コミュニケーションスタイルへの指摘も対象外とする。

### Step 2: 記録する型を分類する

内容が project / reference のどちらかを分類する。どちらでもなければ記録せず、行き先を報告する。既存の記憶ストア内に関連する記録が既にあれば、新規作成ではなく更新を検討する。

### Step 3: テンプレートに沿って記録する

分類した型に対応するテンプレート（references/配下）を使い、frontmatter（name/description/metadata.type）と本文を記述する。**project 型は、いまどこに居て次に何をするかだけを書く。**「How to apply」は書かない。

### Step 4: 索引を更新する

新規・更新した記録への1行ポインタを記憶ストアの索引に追加・更新する。

---

## 出力形式

記録したファイルのパスと分類した型を報告する。

---

## ガードレール

- 特定ツール専用の自動メモリ機構（例: Claude Codeの自動メモリ）への複製は行わない。新規の記録は共有される記憶ストアのみへ書く
- エージェントの恒常的な指示文書（例: CLAUDE.md/AGENTS.md）を直接編集しない。実行環境がそれらの構造化された更新手段を提供している場合はそちらを使う
- advisorのバックボーンknowledgeへの追加候補の検知・審査はこのSkillの責務外。knowledge-cultivatorに委ねる
- 個人の伝え方・コミュニケーションスタイルへのフィードバックは対象外とする
- 採用可否の審査対話は行わない。最小限の記録を即座に行う
- **守ってほしいことを記録しない。**記憶は一時的なものだけを置く場所であり、恒久の決まりを置くと、守らせたい場所（Skill ・ knowledge）に無いまま増える
- **終わった項目を残さない。**当てにならなくなり、次の思考のノイズになる
