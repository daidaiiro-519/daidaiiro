# 図の語彙

**文字だけの枚を作らないためには、図を組む部品が要る。**
`figures/figures.py` が、その部品を持つ。Python 3 の標準ライブラリだけで動く。

## 色を持たないこと

**`figures.py` は色を1つも書いていない。**
テーマの CSS から読む。

```python
from figures import Palette, Figure
f = Figure(Palette.from_theme('../themes/warm-paper.css'))
```

色の正本は `themes/<名前>.css` の1か所だけである。
図の側にも色を書くと、テーマを替えたときに図だけが前の配色のまま残る。

図が使う7つの役割と、テーマのどのトークンから取るかは次のとおり。

| 役割 | 取ってくるトークン | 何に使うか |
|---|---|---|
| `ink` | `--ink` | 図の中の見出し・強い文字 |
| `dim` | `--dim` | 図の中の補足 |
| `line` | `--diagram-line` | 図の線 |
| `panel` | `--surface` | 面 |
| `paper` | `--paper` | 明るい面 |
| `accent` | `--accent` | 強調 |
| `on_accent` | `--on-accent` | 強調面の上に置く文字 |

**図の線は、本文の文字色とは別のトークンから取る。**
同じ色にすると、文字と線が同じ濃さで並び、どちらが構造かが読めなくなる。

## 部品

| 呼び方 | 何が出るか |
|---|---|
| `text(x, y, 行, size, color, weight, anchor)` | 文字。1行でも行の並びでもよい。行間は文字の大きさから決まる |
| `rect(x, y, w, h, fill, r, stroke)` | 面。角丸は既定で12px |
| `path(d, color, width)` | 線。線端は丸め、線幅は既定で2 |
| `arrow(x1, y1, x2, y2)` | 横向きの矢印。矢じりは向きに合わせて付け替わる |
| `circle(x, y, r, fill, stroke)` | 丸 |
| `person(x, y, scale)` | 人。頭と肩の線画 |
| `icon(x, y, 種類, color, scale)` | 絵。8種（下表） |
| `svg(ラベル, 中身, height)` | 図1つを包む器 |

絵は8種ある。**無い名前を渡すと、ある名前を並べて止まる。**

| 種類 | 何を指すか |
|---|---|
| `screen` | 画面・投影 |
| `doc` | 書類・資料 |
| `chat` | 会話・チャット |
| `check` | 済み・決まった |
| `book` | 教材・手引き |
| `search` | 調べる |
| `calendar` | 日程・回数 |
| `branch` | 分岐・枝分かれ |

## 幅は本文に合わせる

`svg()` は幅を **1112px** に固定する。これは本文領域の幅と同じ値で、
図が本文と左右で揃う。**枚ごとに幅を変えない。**

高さだけを `height` で変える。既定は330px である。

`label` は省略できない。何を示す図かを1文で書く ── 読み上げに使われ、
書けないなら、その図は何を示すか決まっていない。

## 図を増やすとき

**場面ごとの図は、関数1つで書く。**
部品を毎回並べ直さない。

```python
def 打ち合わせ(f):
    body  = f.rect(6, 45, 316, 194, f.p.paper, 12, f.p.line)
    body += f.icon(129, 86, 'screen', scale=1.1)
    body += f.text(164, 180, '画面を見せる', 26, weight=700, anchor='middle')
    body += f.arrow(342, 140, 393, 140)
    return f.svg('打ち合わせで画面を見せ、話し、次を決める流れ', body)
```

**新しい分類色を足す前に、位置・ラベル・線の違いで区別できるかを考える。**
色を増やすほど、色覚と投影環境の両方に頼ることになる。
