# 原稿を持つデッキの照合

**原稿（読み上げの台本）を持つデッキは、スライドと原稿を1枚ずつ照合して直す。**
スライドだけ、または原稿だけを直すと、両者の食い違いが残る。
**食い違いは、片方だけを読む限り検出できない。**

この文書は、照合の工程と、1枚ごとに適用する観点の一覧と、最後に出す3つの成果物を規定する。
**設計規則そのものは `design-rules.md` が保持する。この文書は複製しない。**
観点の一覧の中で設計規則に属するものは、その節を指すだけにする。

---

## 1. 照合の工程

**1枚ずつ進める。1枚に全部の観点を適用し、直し、描画して目視し、比較ページへ反映してから次の枚へ移る。**
複数枚をまとめて直すと、前の枚の直しが次の枚の前提を変えたことを検出できない。

| 段 | すること | 省略すると起きること |
|---|---|---|
| 1. 変更前を固定する | 基準の版で全枚を描画し、比較ページの変更前の列に置く | 何を直したかを、読み手が自分で復元することになる |
| 2. 画像と原稿の全文を並べる | その枚の描画した画像と、原稿の全文を並べて読む | 文字の一覧だけの照合では、図の中の食い違いと表示の不良を検出できない |
| 3. 表現の選択を判定する | 主張を1文にし、図の形がその主張を形で示しているかを先に判定する | 形が誤ったまま、余白や文字の大きさの調整を重ねる |
| 4. 観点を全部適用する | §2 の7つの群を、この枚に1つずつ適用する | 報告した観点だけが検査され、ほかは素通りする |
| 5. 直して描画する | 入力を直し、検査を実行し、描画した画像を目視する | 検査が見ない表示の不良が残存する |
| 6. 前後の枚との論を確認する | 直した枚が定義する語と、直した枚を参照する原稿を、前後の枚で確認する | 1枚の中では正しい直しが、前後の枚の論を切る |
| 7. 比較ページへ反映して見せる | 変更後の画像と原稿を比較ページへ入れ、観点ごとに報告し、承認を得る | 利用者は、何が直ったかを文章からしか判定できない |

**全枚が済んだら、§3 の3つを出力する。**

### 表現の選択は、微調整より先に判定する

**利用者が「このデザインでよいか」と問うとき、その問いは多くの場合、形の選択を指している。**
余白・文字の大きさ・行の間隔の調整は、形が正しいときにだけ意味を持つ。

**判定は1つの問いで進む ── この図は、文字を読まなくても主張の関係が分かるか。**
分からないなら、形を選び直す。形の候補は §2.5 が保持する。

## 2. 観点の一覧

**1枚ごとに、7つの群を全部適用する。** 問題が無かった群も「問題が無かった点」として報告する ──
報告に無い群は、適用したかどうかを読み手が判定できない。

各観点は、満たすべき状態で書く。**例は、状態の1つの現れであって、観点の範囲ではない。**

### 2.1 スライドと原稿の整合

| 観点 | 満たすべき状態 |
|---|---|
| 具体の一致 | 図と導入文に置いた具体（数 ・ 日付 ・ 名前 ・ 例）が、原稿にも在る。原稿で説明した要素が、図にも在る |
| 見出しの語 | 見出しで言い切った語を、原稿でも言い切っている |
| 語の一致 | 同じものを、図と原稿で同じ語で呼んでいる。語の正本が在れば、それと照合する |
| 順序の一致 | 原稿で読み上げる順と、図の並び（左から右 ・ 上から下）が一致している |

例：図に「9/16」の日付を置いたのに、原稿がその日付に触れていない。

### 2.2 論とストーリー（枚をまたぐ）

| 観点 | 満たすべき状態 |
|---|---|
| 問いと答え | 原稿で問いを立てたら、次の文がその問いに答えている |
| 定義の順序 | 語は、前の枚か同じ枚で説明してから使っている |
| 参照の範囲 | 「さきほど」「前の」が指す先が、同じ動画の中に在る |
| 重複の排除 | 各枚が、その枚にしかない主張を1つ持つ。同じ例 ・ 同じ図を複数の枚で繰り返していない |
| 言い方の統一 | 同じ対象（例：3つの教材の中身）を、表紙 ・ 目標 ・ 一覧で同じ言い方にしている |
| 抽象の高さ | 目的と身につくものを、手段（道具の名前 ・ 指示に書くこと）ではなく本質で書いている。同じ列に並べる項目の抽象の高さが一致している |
| 移設の影響 | 枚を移す ・ 消す前に、その枚が定義している語と、その枚を参照している原稿を洗い出している |

例：8枚目の原稿が「課題管理表」を使い、それを説明している7枚目を別の動画へ移す案が出る。移すと、8枚目で説明の無い語が出てくる。

### 2.3 日本語

**日本語の規約が、この場に別に在るなら、それを適用する**（`design-rules.md` §7）。
そのうえで、読み上げの文に固有の観点を適用する。

| 観点 | 満たすべき状態 |
|---|---|
| 規約の適用 | 和語の述部 ・ 比喩 ・ 造語を、この場の規約で検査している |
| 根拠の無い強調 | 「確実に」「必ず」などの強調に、根拠が在る |
| 語句の名詞化 | 語句を鉤括弧で括らずに名詞として使っていない（`SKILL.md` のガードレール） |
| 改行の位置 | 図の中の文を、句の途中で改行していない |
| 聞き取り | 同じ助詞が続く箇所（「〜の〜の〜」）を、読点で区切っている |

### 2.4 見出しと導入文

| 観点 | 満たすべき状態 |
|---|---|
| 見出しの主張 | 見出しが、その枚の結論を言い切っている。何が決まるかを言わない形（「〜が決まります」）で終えていない |
| 導入文の役割 | 導入文が、見出しを繰り返さず、図の文とも重複せず、見出しを支える事実か次の主張を1文で示している |
| 帯の向き | 下の帯が、見出しと逆の向き（否定形）になっていない |

### 2.5 図の表現

**主張の関係を、形で示す。** 文字を入れた箱を列に並べ、矢印でつなぐ図を既定にしない ──
その形は関係を示さず、読み手に全部の文字を読ませる。

| 主張の関係 | 示す形 |
|---|---|
| 包含（AがBを含む） | 入れ子の枠 |
| 範囲の広がり | 内側から外側へ広がる入れ子 |
| 期限 ・ 時間 ・ 優先順位 | 線表（時間の軸と、期限の印と、順番の番号） |
| 前と後 ・ いまと解決後 | 同じ部品を左右に置いた対比 |
| 受け渡し | 作業のあいだに、渡すものを置く |
| 発言 ・ 会話 | 吹き出し（地の文と見た目で分ける） |
| 選択 | 並びを見せ、選んだ1つだけを塗る |
| 段階的な上昇 | 階段 |

| 観点 | 満たすべき状態 |
|---|---|
| 記号の意味 | 記号の意味が、置いた対象と一致している。チェック印は済み ・ 正しいを示し、問いの列挙には番号を使う |
| 同じ概念の見た目 | 同じ概念（例：作業）を、図の中で同じ見た目（塗りの向き ・ 枠）で描いている |
| 強調の対象 | 強調は、その枚の主張の1か所と帯だけである（`design-rules.md` §2） |

### 2.6 表示の不良と読みやすさ

| 観点 | 満たすべき状態 |
|---|---|
| 文字の大きさ | 図の中の文字が14px以上である。補足だけを灰色にし、本文は本文の色にする |
| 余白 | 箱の中の最後の行と箱の下端のあいだに余白が在る。見出しと箱が接していない |
| 重心 | 箱の中の要素が上に寄らず、左右の箱と高さの使い方が一致している |
| 線 | 矢印が途中で折れていない。合流点が、合流先の中心と一致している |
| 付属の表示 | 頁の表題 ・ 通し番号が途中で切れていない |
| 検査の外 | 検査が検出しない表示の不良（箱の中心から外れないはみ出しなど）を、画像で確認している |

### 2.7 動画の文体と構成

| 観点 | 満たすべき状態 |
|---|---|
| 位置の説明 | 原稿が、位置だけで対象を指していない（「図の右側で」）。音声だけでは位置が伝わらない |
| つなぎ | 冒頭で前の枚とつなぎ、末尾で次の枚へつないでいる |
| 数の密度 | 1枚の原稿に出る数が、耳で追える量である |
| 文体 | 1本の中で敬体と常体が混ざっていない |

## 3. 最後に出す3つ

**全枚の照合が済んだら、3つをHTMLとPDFで出す。** どれも同じ入力（`review.schema.json`）から組む。

| 成果物 | 中身 | 読み手 |
|---|---|---|
| 台本 | 枚ごとに、変更後の画像と原稿の全文を並べる | 収録する人 ・ 受講者 |
| 確認記録 | 枚ごとに、変更前と変更後の画像 ・ 見出し ・ 原稿の差分（消した文と足した文）と、直した理由を並べる | 承認する人 |
| 観点ごとの結果 | 枚ごとに、7つの群の結果（修正 ・ 問題なし ・ 保留）と、見つけたことと直したことを並べる | 次に直す人 |

**PDFは、HTMLを描画してから書き出す。** PDFを別に組むと、HTMLと中身が食い違う。

## 4. 比較ページ

**照合の途中で、変更前と変更後を並べた比較ページを1枚持ち、1枚直すたびに更新する。**

| 置くもの | 形 |
|---|---|
| 頭 | 何を直したかの要約と、枚ごとの変更の件数 |
| 枚ごとの対 | 左に変更前、右に変更後。どちらも画像 ・ 見出し ・ 原稿を持つ |
| 原稿の差分 | 文の単位で比べ、消した文と足した文を色で分ける |
| 変更の無い枚 | 折りたたむ |
| 追加した枚 | 変更前の列に、追加した枚であることを書く |
| 並べ替えた枚 | 前の位置を書く |

**利用者へ見せる枚の番号には、見出しを併記する。** 数え方が2通り（表紙を含む ・ 含まない）在ると、番号だけでは枚を特定できない。
